## 0. なぜ書き直すのか（記録）

S版の B0 は事前登録の規準で不合格だった（4層中0層、結果 `03_解析/plan_b/B0/B0_positive_control_20260925T231218Z.json`）。
意味内容が既知の方向（人間 valence）が分散プロファイル整合床（PMF, 100 draws）を1層も超えず、層5・7・10 では床を**下回った**（z = −0.94 / −1.99 / −1.86）。
事前登録の結論文「一貫性指標は、意味内容が既知の方向すら検出しない」をそのまま記録した。

**S が不適格である理由（B0 の測定事実から）**:
S は語彙中心化した活性差分の平均対ごとコサインであり、**シフトの形の一貫性**のみを測る。倍率不変（差 < 1e-9）なので効果の大きさを見ない。
したがって刺激集合が等質であるほど 1 に飽和する。PMF 床の sd が層5の 0.0842 から層12の 0.0110 へ縮み、層12 では S ≈ 0.95 で判別の余地がない。
陽性対照が床を**下回った**こと自体が、S が意味内容に感度を持たないことの直接証拠である。

**JS を選ぶ根拠（既存の測定から）**:
出力分布の Jensen–Shannon divergence は既に判別力を示している。層5軸2 は発見群・検証群の両方で α=0.05 において in-plane 床を超え、効果量が δ +0.25 → +0.55 と**増大**した。層7軸1 は両群で α=0.1 / 0.2 を通った。
**動く指標が既にあるのに、動かない指標で選抜しようとしていた。** これは計画の変更ではなく、PI が承認した「出力感度で選抜する」の実装の修正である。

## 1. 立証しようとする命題（PI の構想の再定式化）

PI の構想（2026-09-22）: 「AIは人間にはない、若しくは重要ではない別の概念から感情を構成している。…その概念に適切に介入することで、AIの感情的な振る舞いを操作できる。」

**旧定式化（放棄する）**: 軸が人間の感情部分空間と**幾何的に直交する**。
放棄の理由は2つ。(a) 我々のデータが逆を向いている。置換帰無に対する相対量で 12セル中8セルが偶然を上回り、倍率は最大 12.5倍（偶然水準 0.146% = 3/2048）。つまり軸は人間の感情部分空間の内側に無作為方向より**多く**入っている。(b) 幾何的直交の主張は先行研究が既に踏んでいる。

**新定式化（本事前登録）**: 軸は、**人間の VAD 方向への介入では再現できない出力変化を生む**。
幾何がどうであれ、出力の変化が人間の軸の線形結合で張れないなら、それは人間の枠組みに還元されない概念である。
PI 承認（2026-09-26）: 「私の言ったような仮説（もしくはそれに近いもの）が立証されるならあなた自由に調整して良いです。」

**立証に必要な連言**: 単独では何も言えないことを明記する。
無作為方向も「人間 VAD に還元不能」ではある（高次元では任意の2方向はほぼ直交する）。
したがって**還元不能性だけでは主張にならない**。以下4条件の連言が主張である。

1. その軸への介入が**分散を揃えた床を超える出力変化**を生む（G1）
2. それが**独立な分割で再現する**（G2）
3. その出力変化が**人間 VAD 方向の介入では張れない**（G3）
4. その介入が**精度／トークンのトレードオフを既存手法より改善する**（G4）

### G1: 出力感度で選んだ軸が分散整合床を超えるか（発見群のみ）

- **候補軸の母集団（事前に固定）**: 各層の活性に対する ICA 成分（rank 20 まで、S版と同一の抽出手続き・シード）。**加えて上位10主成分そのもの（PC1–PC10）を候補に含める。** PC を含めるのは、S版で PC1–PC5 が ICA 軸と同等以上の効果を出したという測定事実があるためで、**「軸」が PC の再記述に過ぎないなら、それが選抜結果に現れるようにしておく**

## 4. JS の定義（実装を一意に固定する）

- 介入は残差ストリームへの forward hook による加算。注入位置 = **刺激末尾トークン**（論文1で位置により符号が反転することが分かっているため、位置を固定し、**プロンプト末尾は感度分析としてのみ測る**）
- 係数 = 当該層・当該刺激の残差ノルム平均に対する比。**グリッド = {0.5, 1.0, 2.0, 4.0}**（4点）。主判定は **1.0**
- 出力分布 = 介入直後の次トークン分布（語彙全体、温度1、単一 forward）。**生成はしない**（生成を入れると判定器が必要になり、B0 の教訓どおり交絡が増える）
- JS = 介入前後の次トークン分布間の Jensen–Shannon divergence（底2、単位 bit）。刺激ごとに計算し、**刺激をまたいだ平均**を統計量とする
- **符号の扱い**: +α と −α の両方を測り、**JS は対称なので両者の平均**を用いる。片側だけを選ばない
- 層 = **5, 7, 10, 12**（S版と同一。変更しない）
- 数値の再現性: seed 20260926、torch deterministic、bf16 不使用（fp32）。環境と prereg commit を全出力に記録

## 5. PMF 床の定義（S版から変更しない）

分散プロファイル整合床。軸の主成分への二乗射影を保存したまま、(a) 符号を無作為化、(b) 固有値が近い主成分の間で係数を置換、(c) 直交補空間を無作為回転。
**乱択数 = 100**（B0 で 20 では p 分解能 1/20 となり q < 0.05 に到達できないと判明したため。規準の緩和ではない）。

**追加の記述的確認（判定には使わない）**: G1 を通った軸と通らなかった軸で、分散プロファイル（上位10主成分への二乗射影の分布）が系統的に違わないかを記述的に示す。
中村の指摘（2026-09-26）による。**判定に使うと選抜と検定が循環するため、記述にとどめる。**

## 6. G3 の手続き（詳細）

1. G2 を通ったセル (層 L, 軸 a) を取る
2. 軸 a への介入（係数 1.0）で、刺激ごとの**出力変化ベクトル** Δ_a を得る。Δ_a は介入前後の次トークン対数確率の差（語彙次元）。刺激方向に連結して1本の長いベクトルとする
3. 人間 VAD 3方向 h_V, h_A, h_D（Warriner 規範から推定。推定手続きとシードを記録）について、**係数を掃いて JS の大きさを Δ_a の JS に一致させる**（相対誤差 5% 以内。達成できない方向はその旨を記録し、最も近い係数を使う）
4. 得られた Δ_V, Δ_A, Δ_D を説明変数として Δ_a を最小二乗回帰し、**R²_reduce** を得る
5. ブートストラップ（刺激をリサンプル、2000回）で R²_reduce の95%CI を得る
6. **参照値として、人間方向どうしの還元可能性も測る**: Δ_V を {Δ_A, Δ_D} で回帰した R² を報告する。これが「還元可能」の水準の目安になる

**事前の注意**: 高次元では無作為な2方向の R² は小さくなる。したがって **R²_reduce が小さいこと単独では何も示さない。** G1・G2 を通ったことと連言でのみ意味を持つ。原稿でもこの順序で書く。
