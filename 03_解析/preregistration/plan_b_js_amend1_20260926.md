## A1. 介入の形を1つ増やす（最も重要な変更）

**問題の再認識**: 加算介入 x ← x + αd では、下流が受ける変化は「その方向に沿って既にある分散」と結びつく。
PMF 床はこの交絡に**事後的に対処する patch** であって、機構そのものは残っている。

**変更**: 以下2つを**同格の主腕**として測る。

- **腕 I（加算）**: x ← x + αd。α は残差ノルム平均比 {0.5, 1.0, 2.0, 4.0}、主判定 1.0（元の事前登録どおり）
- **腕 II（鏡映・等長）**: x ← x − 2(x·d)d。**ノルムを保存し、d 以外の成分を変えない直交変換**。係数を持たないので用量の選択が不要

**なぜ等長が交絡に効くか**: 鏡映は直交変換なので、活性集合の共分散構造を保存する。
「大分散方向だから大きく足される」という経路が存在しない。変化量は「その方向に既にある射影値」で決まり、それは無作為方向でも同じ分布から引ける。

**判定への影響**: G1 の通過条件は **腕Iと腕IIのいずれかで満たせばよい**とする。両腕の結果を必ず併記する。
**腕Iで通り腕IIで通らない場合、それは「効果が加算の大きさに依存する」ことの証拠であり、そのように書く。** 都合の良い腕だけを報告しない。

**追加の記述（判定に使わない）**: 腕Iと腕IIで軸の順位が入れ替わるかを報告する。入れ替わるなら、加算介入を使う既存研究の結論が介入形式に依存することを示す方法論的所見になる。

## A2. 候補方向の探索空間を広げる（分散と独立な基準を1つ入れる）

**変更**: §2 G1 の候補軸母集団に、以下を**追加**する（既存の ICA rank20 と PC1–PC10 は残す）。

- **感度方向**: 層Lの残差から出力ロジットへのヤコビアンの上位特異ベクトル（上位10本）。**モデルが敏感な方向**であり、データの分散とは独立に定義される
- 各候補方向を **(分散, 感度) の2次元に配置して図にする**。狙うのは**低分散・高感度**の象限

**なぜ入れるか**: ICA 軸が「高分散・高感度」にしか存在しないなら、軸は分散の副産物である。
**低分散・高感度の方向が実在して床を超えるなら、分散では説明できない。** どちらに転んでも一枚の図で決着する。

**計算**: forward + backward のみ。生成不要。数百プロンプトで足りる。

## A3. 分散→効果の較正曲線を引き、超過分を報告する（PMF の一般化）

**変更**: 各層で、**分散スペクトルの全域から層化抽出した無作為方向300本**について JS を測り、**分散対 JS の非パラメトリック回帰（等調回帰）**で較正曲線を得る。
軸の効果は、この曲線からの**超過（残差）**として併記する。

**位置づけ**: **判定は PMF 床のまま**（元の事前登録を変えない）。較正曲線は**記述の追加**である。
PMF は「同じ分散プロファイルの方向と比べる」、較正曲線は「分散から予測される効果を差し引く」。**両方報告し、結論が一致するかを見る。**

## A4. G3 の操作的定義を鋭くする（3条件に分解）

**変更**: §2 G3 の判定を、R²_reduce < 0.50 に**加えて**以下3条件の充足状況を報告する形にする。

1. **出力が自然である**: 介入後の継続の対数確率低下が、腕ごとに事前指定した閾値以内（加算腕は係数1.0で低下 ≤ 0.30 nat、鏡映腕は ≤ 0.30 nat）
2. **人間の感情語彙に寄らない**: 語彙を人間の感情語に限定した次トークン分布が、介入後も**平坦**（中立条件に対する KL が、人間 valence 方向介入時の KL より小さい）
3. **それでも中立から離れている**: 全語彙 JS が床を超えている（= G1 の条件）

**主判定は R²_reduce のまま。** 3条件は**同時に報告**し、3つとも満たす軸があれば「**人間の語彙では名指しできないが出力を系統的に動かす状態**」として記述する。

**理由**: R²_reduce が小さいだけでは無作為方向と区別できない（高次元では任意の2方向がほぼ直交する）。**3条件を連言にすると、無作為方向は条件1で落ちる。**
