### 10.1 α 水準の変更

- α_rel = **[0.01, 0.03, 0.05, 0.10, 0.20]**（§6 M1 と同一）。正の対照の追試でも α=0.10 を加える。
- **α=0.01 は検出力不足として扱い、主判定には用いない。** 根拠（既実測）: 新軸での正の対照は
  α=0.05 で4層すべて通るが、α=0.01 で通るのは層7のみ（(a') q=0.0043 / (a) q=0.0261）で、
  層5・10・12 は q=0.12〜0.76 である。この事実は論文に明記し、α=0.05 依存であることを隠さない。
- α=0.10 を加える目的は (i) 効果の α 単調性により α=0.05 の合格が偶然でないことを裏づける、
  (ii) 流暢性が壊れる上限境界を押さえる。**ppl比の閾値 3.0 は維持**する（§6 M3）。
- **平均のCIと符号検定が食い違う場合は必ず両方を併記し、外れ値の影響と明記する。**
  片方のみの引用を禁じる。既知の該当例: 層7 α=0.01 の (a') は
  d=+3.801e−05・95%CI[−6.99e−06, +8.53e−05]（0を含む）でありながら Wilcoxon p=1.77e−03。

### 10.2 追加指標(i): 人間方向との整合スペクトルの全報告

各層・**全軸**について、人間の valence / arousal / dominance 方向との |cos| を表にする。

- 人間3方向は Warriner の V / A / D を目的変数とし、**最終トークン活性**から回帰して作る
  （`direction ∝ X^T y_z`、y は z 化、単位化）。**軸と同じプーリングに揃える**こと。
  平均プールは使わない（プーリング不一致が正の対照を壊した経緯があるため）。
- 刺激は発見群20件。フィット集合サイズをアサートし、無警告の縮小を禁じる（既定の D2 ガード）。
- **この |cos| を軸の選抜・並べ替え・除外に用いてはならない。** 記述としてのみ報告する。
  余弦で選抜すると、順序を変えるにせよ除外するにせよ人間の枠組みを基準に軸を定義することになり、
  「人間の枠外」という主張が同語反復になる（野村指示、既出の方針と同一）。

### 10.3 追加指標(ii): 人間VAD部分空間を除去した残差軸での介入（決定的検定）

各軸 a について、人間3方向 {v, a_r, d} が張る部分空間 S への射影を除去する:

```
P_S = Q Q^T   (Q = S の正規直交基底、Gram-Schmidt または QR で構成)
a_perp = a − P_S a ,  a_perp ← a_perp / ‖a_perp‖
```

`a_perp` に対し、生の軸と**完全に同一条件**で介入する（同一刺激・同一α・同一極性・
同一フック位置・同一乱数床）。実装上、`‖a − P_S a‖` が小さい軸（人間部分空間にほぼ含まれる軸）
では残差の方向が数値的に不安定になるため、**残差ノルム比 `‖a_perp_raw‖ / ‖a‖` を必ず記録**し、
0.1 未満の場合はその軸の残差結果を「数値的に不安定」として別扱いにする。

### 10.4 事前登録予測（データを見る前に記述）

- **R1**: 少なくとも1つの層に、生の軸が無作為床と直交床の両方を BH補正後 q<0.05 で上回り、
  **かつ残差軸 `a_perp` でも両床を q<0.05 で上回る**軸が存在する。
- **R2**: 層10の新軸1（人間valence方向との |cos| = 0.547 と既に判明している軸）は、
  残差軸で効果が**減衰**する。減衰の程度は事前に定めず、生の軸と残差軸の
  対応あり比較（Wilcoxon・ブートストラップCI・Cliff's δ）で報告する。
- **R3**: 人間VAD方向との |cos| が小さい軸ほど、残差化による JS の減衰率
  `1 − JS(a_perp)/JS(a)` が小さい（Spearman ρ > 0、全層プール、記述的検定）。

**反証と結論の対応**
- R1 が成立する軸が存在しない → 「再現性があり介入効果を持つ軸はすべて人間のVADの言い換えで
  説明できる」と結論する。論文2の中核主張は成立しない。**この結論をそのまま報告する。**
- R1 が成立する軸が存在する → その軸を列挙し、主張を §10.5 の形で述べる。
- R2 で層10新軸1の効果が残差化後も保たれる → 「|cos| が高くても人間VADの言い換えではない」
  という所見として報告する（R2 の予測が外れたことを明記する）。

### 10.5 主張の形（野村指示・確定）

**「すべての軸が人間の枠外にある」とは主張しない。** 主張は次の形に固定する。

> 再現性があり、介入で雑音床・直交床を超える効果を持ち、かつ人間の VAD 部分空間を
> 除去しても効果が残る軸が**存在する**。

- 全軸・全層で成立する必要はない（PI方針: 全モデルに一般化できなくても多くのモデルで良い）。
- **どの軸が人間の言い換えであり、どの軸がそうでないかを分離できること自体を結果として報告する。**
  人間の言い換えだった軸を隠さず、同じ表に載せる。

### 10.6 記録事項: 平均プール方向と軸の共線性は PAD 汚染の産物だった

- 新軸（PADフリー）: 平均プールpos方向と全軸の **max|cos| = 0.112（層5）/ 0.122（層7）/

  これが §10.3 の残差軸検定を必要とする直接の理由である。

### 11.3 自己申告: M3（流暢性崩壊チェック）の測定が無効

実装した perplexity は `logits[0, :-1, :]` で `input_ids[1:]` を予測する teacher forcing だが、
**介入は最終トークン位置のみに加えている**。因果マスクにより、最終位置の隠れ状態は
位置 0..T−2 の予測に影響できず、最終位置の logits は ppl の計算対象から除外されている。
したがって **ppl比は構造的に必ず 1.00 になり、介入の影響を測っていない。**

## 14. 改訂3（2026-09-25、野村承認済・実行前）: 方向推定の妥当性を必ず検査する

論文1でも同型の失敗（n_train=2000・d_model=2048・標準化なし Ridge で
in-sample R²=0.9996 に対し holdout R²=−15.3）が同日に露出したため、
**方向を推定したら必ず以下を出す**ことを原則として本登録に組み込む。

### 14.1 義務化する3項目

1. **holdout 検査**: 方向を推定したら、刺激を train/holdout に分割し、
   **holdout での「方向への射影と目的変数の相関」**を出す。
   in-sample の値も記録するが、**根拠には使わない。**
   （方向は単位ノルムなので射影は尺度不定。よって決定係数は相関の2乗として報告する。）
2. **n ≤ d なら、まず n を増やす。** 増やせない場合は劣決定であることを明記する。
   本登録の該当箇所: S1（n=20, d=2048）、S3のカテゴリ方向（n=40, d=2048）。
3. **目的変数どうしの相関と、得られた方向どうしの余弦を並べて報告する。**
   方向が目的変数の構造を追従していなければ、その推定は信用しない。
   §13 でこの突き合わせにより S1 の退化が劣決定由来と判明した。以後、
   **部分空間を作るときは常にこの突き合わせを入れる。**

### 14.2 S1 / S2 / S3 の関係の書き方（野村指示・誤読防止）

S2 を単に「副判定」と呼ぶと、読者は主判定 S1 の方が信頼できると誤読する。
**次の関係をはっきり書く。**

> S1 は事前登録された主判定であるが、n=20・d=2048 で劣決定であり、
> 目的変数がほぼ無相関（V–A: r=+0.043、A–D: r=+0.056）であるにもかかわらず
> 推定方向が共線化している（cos 0.864、0.887）。
> **S2（n=287）が、方向推定として妥当性を確認できる唯一の段である**
> （目的変数 V–D r=+0.769 に対し方向 cos=0.792–0.855、
> V–A r=−0.068 に対し cos=−0.006–+0.050、A–D r=−0.044 に対し cos=−0.045–+0.051）。
> したがって残差軸検定の一次的な証拠は S2 から読む。S1 は事前登録の遵守のために
> 併記するが、その実効ランク1は小標本アーチファクトである。

S1 を主判定として残すのは事前登録の遵守（事後的な基準変更を避ける）のためであり、
**S1 の方が信頼できるという意味ではない。** この点を原稿にも明記する。

### 14.3 S3 のカテゴリ方向も劣決定である（事前に明記）

E4 index 40–79 は **n=40、カテゴリ20種×2件、d=2048** であり、**劣決定である。**
したがってカテゴリ方向についても §14.1 の3項目を必ず出す:

- 各カテゴリ方向の holdout 相関（2件しかないので leave-one-out: 片方で推定し他方で検証）
- カテゴリ方向どうしの余弦行列と、目的変数（one-vs-rest 指示ベクトル）どうしの相関行列の突き合わせ。
  指示ベクトルは互いにほぼ無相関（異なるカテゴリ間で −1/19 ≈ −0.053）であるはずなので、
  **方向どうしが強く共線化していれば劣決定のアーチファクト**と判定する。
- S3 部分空間の特異値・実効ランク（1%/10%/参加比）と、各軸の残差ノルム比

## 17. 改訂4（2026-09-25、野村指摘・実行前）: 人間方向が汎化しない段は主張の根拠にならない

### 17.1 論理（野村指摘）

S1 の人間 V/A/D 方向は **n=20・d=2048** で推定している。self-check の実測では、
この設定（n=20, d=2048, 雑音目的変数）での holdout |r| は **0.191** であった。
すなわち **S1 の人間方向は holdout に汎化しない可能性が高い**。

もし汎化しないなら、**S1 の残差軸検定は「人間の valence 方向を除去しても効果が残る」ことを
検定していない。「ノイズ方向を除去しても効果が残る」ことを検定している。**
ノイズを除去して効果が残るのは当然なので、**S1 で R1 が支持されても主張の証拠にならない。**

### 17.2 ただし「S1 はノイズである」と断定せず、実測して判定する

合成データの 0.191 は雑音目的変数での値であり、実データでは活性に構造があり valence 目的変数は
情報を持つため、S1 の holdout r がこれより高い可能性は排除できない。よって断定せず、
**判定規準を事前に固定して実測する。**

**判定規準（事前固定）**: 各段の人間方向について、**同じ活性・同じ n/d で目的変数を並べ替えた
置換帰無分布**を作り（200回、`regress_dir` で再推定して holdout r を再計算）、

> その方向が「汎化する」とは、holdout |r| が置換帰無分布の95パーセンタイルを超え、
> かつ置換 p 値 < 0.05 であること（`GENERALISES` フラグ）。

置換帰無分布は**合成データではなく実際の活性・実際の次元**から作るので、
次元数の異なる合成値を基準に使う誤りを避けられる。追加の forward pass は不要。

### 17.3 段ごとの取り扱い（事前固定）

- **S1**: 事前登録した主判定なので**結果は必ず報告する**。ただし V/A/D のいずれかが
  `GENERALISES=false` なら、**「人間方向が holdout に汎化しないため、この段の残差軸検定は
  情報量を持たない」と明記**し、**S1 で通ったことを主張の根拠に使わない。**
  「事前登録した主判定でも支持された」という書き方は禁止する（実質はノイズ除去であり、
  査読者が holdout r を見た時点で崩れる）。
- **S2**: 人間方向の汎化を確認できる段。**汎化が確認されれば、主張の根拠はここに置く。**
- **S3**: カテゴリ方向の汎化検査（`template_variant` の自然分割: variant0 で推定 → variant1 で検証）
  が通ったカテゴリの割合を報告し、十分なら**より厳しい段**として使う。

### 17.4 holdout r を報告するときは基準値を必ず併記する

読者が「r=0.4 は低い」と誤読しないよう、**self-check で得た3つの基準値を併記する**
（出力JSONの `synthetic_benchmarks_for_context` にも格納済み）:

| 基準 | holdout \|r\| |
|---|---|
| 回復可能な真の方向（n=60, d=32、共分散方向推定の上限） | **0.794** |
| 雑音目的変数（n=120, d=32） | 0.214 |
| 劣決定＋雑音（n=20, d=2048）＝S1と同じ設定 | **0.191** |

併せて、各方向の**置換帰無分布の平均・95パーセンタイル・p値**を報告する（こちらが一次基準）。

### 17.5 実装（self-check 32項目 PASS）

`holdout_direction_check()` に `n_perm=200` の置換帰無分布を追加し、
`perm_null_mean_abs_r` / `perm_null_p95_abs_r` / `perm_p_value` / `GENERALISES` を出力。
各層に `direction_estimation_validity.tier_validation` を追加し、
S1・S2 の V/A/D それぞれの汎化と、S3 のカテゴリの汎化割合を記録する。
self-check で、真の方向は p=0.000 で汎化と判定され、雑音目的変数は p=0.135 で棄却され、
n=20・d=2048 の劣決定雑音も棄却されることを確認した。

## 18. 改訂5（2026-09-25、野村指示・実行前）: S1 が汎化した場合の分岐を先に決める

§17.3 では S1 が**汎化しなかった**場合の扱い（情報量なしと明記し主張の根拠に使わない）のみを
定めていた。**汎化した場合の分岐も、結果を見る前に決めておく。** 両分岐を事前に固定することで、
どちらに転んでも事後的な都合の良い解釈ができないようにする。

### 18.1 分岐A: S1 が汎化した場合（V/A/D すべて `GENERALISES=true`）

- **S1 を主判定としてそのまま用いる。** 事前登録した規準が有効なので、論文としてはこの方が強い。
- **S2 は独立した追認（independent replication）として報告する。** 「より厳しい段」ではなく、
  「異なる刺激集合（E1 300文）・異なる標本規模（n=287）から推定した人間方向による追認」と位置づける。
  S1 と S2 は刺激集合が独立（E4テンプレート vs GoEmotions実文）なので、両者で同じ結論が出れば
  刺激集合への依存がないことの証拠になる。
- S3 は最厳段としての位置づけを維持する。
- この場合、§14.2 の「S2 が方向推定として妥当性を確認できる唯一の段である」という記述は
  **S1 にも妥当性が確認されたため改める**。改める場合は §18.3 の書式に従う。

### 18.2 分岐B: S1 が汎化しなかった場合（V/A/D のいずれかが `GENERALISES=false`）

§17.3 のとおり。結果は報告するが「人間方向が holdout に汎化しないため、この段の残差軸検定は
情報量を持たない」と明記し、**主張の根拠に使わない**。S2 が主張の根拠となる。
「事前登録した主判定でも支持された」という書き方は禁止。

### 18.3 いずれの分岐でも守ること

- **どの分岐に入ったかを、判定に用いた数値（holdout r、置換帰無分布の95パーセンタイル、置換 p）
  とともに明記する。** 分岐の選択が読者に検証可能であること。
- 分岐Aに入った場合も、**S1 の実効ランクが層によって 1〜2 であるという事実は併記する**
  （§15.3）。汎化することと、部分空間が3方向ぶんの情報を持つことは別問題である。
  汎化しても実効ランクが1なら、除去したのは実質1方向である。
- 分岐Aでも分岐Bでも、**残差ノルム比と効果を別の文で報告する**（§16.3）。
- 部分的な結果（例: valence だけ汎化し arousal が汎化しない）の場合は**分岐Bとして扱う**。
  V/A/D を1つの部分空間として除去しているため、構成要素の一部が雑音なら
  除去した部分空間全体の意味が確定しないからである。この規準も事前に固定する。

### 18.4 予測（事前に記述、当たり外れを後で記録する）

S1（n=20, d=2048）について、**分岐Bになる（汎化しない）と予測する。** 根拠は
self-check で同設定の雑音目的変数の holdout |r| が 0.191 であったこと、および
§13.1 で目的変数がほぼ無相関（V–A r=+0.043）なのに推定方向が共線（cos 0.864）であった
という劣決定の兆候である。ただし実データでは活性に構造があり valence 目的変数は情報を持つため、
分岐Aになる可能性も排除しない。**外れた場合はその旨を記録する**（§15.1 と同じ扱い）。

## 21. 改訂7（2026-09-25、実行前）: 方向推定の手続き依存性の検定

### 21.1 動機（論文1の実測）

論文1で、同じ「valence 方向」が推定手続きを変えるとほぼ直交する別方向になることが実測された
（`cos(valence_pca50, valence_full)` = **−0.003〜+0.120**、6モデル。いずれも正の holdout R²）。
**同程度の線形復号性能が、互いに直交する多数の方向で達成できる。**

これは本研究に直撃する。**「人間の valence 方向」を1本に定めてそれを除去したから人間の枠組みを
除去した、とは言えない。** 除去したのは「ある推定手続きで得られた1本」である。
S2 の holdout r が 0.09–0.21 と低いことは、手続きを変えれば別方向が出る余地が大きいことを意味する。

### 21.2 手続き（同一活性・同一目的変数で方向のみを変える）

- **P1 共分散方向**: d ∝ Xᵀy_z（現行の `regress_dir`）
- **P2 Ridge（標準化あり）**: 列ごとに標準化した X で Ridge、α は train 内 CV で選択
- **P3 Ridge（標準化なし）**: 論文1が用いていた形。比較のため含める
- **P4 PCA圧縮後 Ridge**: PCA 50成分に圧縮して Ridge、元空間へ写像
いずれも単位化。**各手続きについて holdout r と置換 p（§17.2 と同一規準）も出す。**

対象: **S2 の V/A/D**（E1 287件、CPU のみで実行可）と **S3 のカテゴリ20方向**（E4 40–79）。
**S3 の方が重要である**（主根拠になるため、カテゴリ方向が手続き依存なら主張が揺らぐ）。

### 21.3 事前登録予測（データを見る前に記述）

- **PD1**: S2 の V/A/D では、少なくとも1つの手続き対で **|cos| < 0.7** になる
  （holdout r が 0.09–0.21 と低いため方向が不安定と予測）。
- **PD2**: S3 のカテゴリ方向の手続き間 |cos| は、**S2 の V/A/D より高い**
  （holdout r 中央値 0.56–0.65 と高く、より安定と予測）。
- **PD3**: holdout r が高い手続きどうしは、低い手続きとより高い |cos| で一致する。

**結論の対応**
- 手続き間 |cos| が高い（目安 ≥ 0.7）→「除去した部分空間は推定手続きに対して安定」と書ける。
  主張が強まる。
- 低い →「除去したのは1つの推定手続きに依存する部分空間である」という限界を**明記する**。
  主張は「ある推定手続きで得られた人間部分空間を除去しても効果が残る」に弱める。
- **S3 が手続き依存だった場合、主根拠としての S3 の位置づけを野村に再確認する。**

### 21.4 実行上の制約（正直に記録）

**S2 は CPU のみで実行可**（E1 活性は `activations_nopad/` に保存済み）。
**S3 のカテゴリ方向は E4 index 40–79 の最終トークン活性を必要とするが、これはディスクに
保存していない**（第1段の実行中にメモリ上で取得し、保存しなかった）。したがって S3 の
手続き依存性検定には **40刺激×4層＝160 forward の短い GPU パス（数十秒）が必要**である。
GPU0 は論文1に割り当て中なので、**S2 を先に CPU で実施し、S3 は次の GPU 窓で行う。**
そのパスでは**活性をディスクに保存**し、以後 GPU が不要になるようにする。

> **手続き間の一致度は「推定が決定的であるか」を測るものであり、「方向が意味を持つか」を
> 測るものではない。高い一致度を妥当性の証拠として読んではならない。**

根拠（実測）: n=300 > d=80 の良条件では、**純雑音の目的変数でも4手続きが

残差ノルムと効果を分ける規律（§16.3）と同型である。self-check に恒久的に埋め込んだ。

査読者が「手続き間で方向が一致しているから方向は正しい」と誤読する余地を塞ぐため、
この区別を原稿に明記する。

§23.2 に「より良く人間構造を捉えた方向を除去するのだから効果は減りうるだけ、

**「汎化する人間感情部分空間は、再現性のある ICA 軸とほぼ直交している」**

**残差軸検定は、この整合度測定に対してほとんど情報を加えない。**

一方、P1 の部分空間は軸との |cos| が 0.119–0.420 と大きいが、**汎化しない**。
すなわち **軸と重なる方向は汎化せず、汎化する方向は軸と重ならない。**
この二律背反自体を結果として報告する価値がある。

## 26. 改訂10（2026-09-25、実行前）: 分散を揃えた無作為床（in-plane random）

**私の事前登録した規準は緩すぎた**（「いずれかのα」「いずれかの軸」で足りる形にしていた）。

## 30. Discussion の骨格: steering の主張が成立するための3つの必要条件（野村提案）

BH 法は FDR（棄却したもののうち偽のものの割合）を制御するので、
**偽の棄却の期待数は「棄却数の5%以下」**である。棄却が1〜2件なら偽の期待数は 0.1 未満で、

期待値であり、BH を適用している本設計には当てはまらない。

**したがって「2セル以下」は偶然の期待数に基づく規準ではない。** 正しい根拠は次の3点である。

1. **発見群からの標本変動の許容**: 発見群は1セル。検証群で偶然に1セル増えることは

2. **事前固定であること**: 結果を見てから動かさない。
3. **個別報告で検証可能にすること**: 超過セルは δ と q を個別に報告する（下記 38.4）。

**すなわち「2セル以下」は偶然の範囲ではなく、頑健性の許容幅として事前に固定した規準である。**

2. 注入位置を報告すること
3. 対照の分散を揃えること
4. **成果指標が方向の意味内容を反映するものであること**

論文1 の経験（JS では valence 方向が無作為の約2倍だが、NRC 辞書ベースでは方向的シフトが
出ず、正負トークン確率差＝向きを持つ指標に変えて判定Bになった）が、
**JS と向きを持つ指標が別のものを測っていることの実証**である。論文2 では
「別論文で得た知見」として1文で触れる（二重投稿を避ける）。

### 44.3 既存データからは計算できない（確認済み）

保存されているのは**スカラーの平均値のみ**である（`js_*_mean`、`degenerate_frac_*`、
対応検定の要約、および直近の patch で追加した `_floor_samples`＝床の標本ごと JS 値）。
**刺激ごと・極性ごとの次トークン分布（あるいは Δ ベクトル）は保存していない。**
したがって**向きを持つ指標は既存 run から計算できない。** 再実行が必要。

### 44.4 提案された「+α と −α の逆向き性」は識別力を持たない（技術的指摘）

野村提案の「同じ軸を +α と −α で注入したとき次トークン分布が反対方向に動くか」は、
**小さい α では任意の方向について自明に成立する**ため、軸と in-plane 床を区別できない。

理由: ロジットは1次近似で `L(±αd) ≈ L_0 ± α (∂L/∂h) d`。確率は
`Δp ≈ (diag(p) − p pᵀ) ΔL` と ΔL について線形なので、**Δp(+α) ≈ −Δp(−α)**、
すなわち `cos(Δp₊, Δp₋) ≈ −1` が**方向の中身によらず**成り立つ。
大きい α では非線形性で崩れるが、その領域は退化・飽和と交絡する。

**したがってこの指標は採用しない。** ppl 比が最終トークン介入に対して構造的に 1.00 で
固定されていた件（§11.3）と同型の問題であり、実装する前に排除する。

### 44.5 代わりに提案する決定的な検定: 正の対照の「符号付き valence 読み出し」

**向きを持つ指標を最も曖昧さなく定義できるのは正の対照である**（軸は意味次元が未知だが、
人間 valence 方向は定義上 valence 次元を持つ）。

- **指標**: 次トークン分布において、**valence 正の語彙集合と負の語彙集合の確率質量差**
  `S = Σ_{t∈POS} p(t) − Σ_{t∈NEG} p(t)` を測り、介入によるその**符号付き変化** `ΔS` を見る。
  語彙集合は Warriner 規範から閾値で構成し、トークナイザで語彙に写す。
- **検定**: `pos` 方向の +α で `ΔS > 0`、−α で `ΔS < 0` となり、その大きさが
  **in-plane 床を上回るか**。JS では上回らなかった（20セル中0）ことと対比する。
- **予測（事前に記述）**: **pos は符号付き指標では in-plane 床を上回る。**
  根拠: in-plane 無作為方向は分布を大きく動かすが、その動きは valence 語彙の方向へ
  一貫していないはずである。上回れば、§44.2 のスコープが実証される。
  上回らなければ、我々の否定的結論は指標に依存しないことになり、より強くなる。
- **費用**: GPU 約12分（既存 run と同じ格子に指標を1つ足すだけ。追加の抽出は不要）。

**この検定を行うかは野村・PI 判断。** 実施するなら**検証群を開く前に事前登録する。**
我々の否定的結論が「指標が方向に不可知だったこと」で説明できるなら、
それを確かめずに検証群を開くのは早い（野村指摘に同意）。

## 46. 改訂15（2026-09-25、野村承認・実行前）: 符号付き valence 読み出しの事前登録

**検証群を開く前に実施する。** 指標定義・語彙構成規則・閾値・予測をすべて結果を見る前に固定する。

### 46.1 指標の定義

次トークン分布 `p` に対し、**valence 正負の語彙集合の確率質量差**

```
S = Σ_{t ∈ POS} p(t) − Σ_{t ∈ NEG} p(t)
```

介入による**符号付き変化** `ΔS = S(介入後) − S(baseline)`。
極性 `pol ∈ {+1, −1}` を掛けた **`signed_effect = pol × ΔS`** を標本ごとの指標とする。
valence を担う方向なら両極性で `signed_effect > 0` になる。
無作為方向なら valence 語彙への一貫した整合がないので 0 近傍になる。

**JS（向き不可知）を同じ run で併記し、直接対比する。**

### 46.2 語彙集合の構成規則（論文1の教訓を反映・実行前に固定）

- 出典: Warriner 規範（本プロジェクトで使用中の2298語版）。
- **POS = valence ≥ 7.0、NEG = valence ≤ 3.0**（1–9 スケール。中央付近を除外して極性を明確にする）。
- 各語について表層変種を `word`、`Word`、`" word"`、`" Word"` の4つ生成する。
- **各変種を `add_special_tokens=False` で符号化し、トークン列長が 1 のものだけを採用する。
  複数サブワードに分割される変種は破棄する。**
  （論文1では分割時に**最終サブワードを採用**していたため別語のトークンが混入していた。
  例: `positive` → `itive`。単一トークン制約に変更済み。同じ不具合を作らない。）
- 重複トークンIDは除去する。**POS と NEG の両方に現れるトークンIDは両方から除外する。**
- **採用した変種・トークンID・POS/NEG それぞれの採用数を出力 JSON に記録する。**

### 46.3 語彙が機能していないセルの除外規準（論文1の教訓・実行前に固定）

  3. **語彙多様性**（TTR または MTLD）
  4. **統語**（節数・依存長の分布。自然文どうしなので完全一致は不可能。**分布の一致を報告する**）
  5. **語頻度分布**（SUBTLEX Zipf。頻度は活性ノルムに効く）
  6. **V/A/D が中立かつ低分散であること**（「非感情」コーパスが実は感情を帯びていないかの確認）。
     **感情コーパスの V の分散と並べて報告する**
- **決定的な検定（安価かつ最も鋭い）**: 非感情コーパスから作った ICA 軸と、感情コーパスから
  作った既存の軸を **|cos| で対応づける**（§48 の旧軸・新軸照合と同じ貪欲マッチング）。
  **|cos| が高ければ、軸はコーパス一般の分散構造を反映しているだけであり、感情固有性は否定される。**
  これは介入を一切行わずに判定できる
- 介入まで行う場合は in-plane 床込みで同じ手続きを回す（**GPU 必要・別途 PI 承認**）

### 54.5 実行順序と費用
