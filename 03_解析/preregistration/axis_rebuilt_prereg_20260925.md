### 10.1 α 水準の変更

- α_rel = **[0.01, 0.03, 0.05, 0.10, 0.20]**（§6 M1 と同一）。正の対照の追試でも α=0.10 を加える。
- **α=0.01 は検出力不足として扱い、主判定には用いない。** 根拠（既実測）: 新軸での正の対照は
  α=0.05 で4層すべて通るが、α=0.01 で通るのは層7のみ（(a') q=0.0043 / (a) q=0.0261）で、
  層5・10・12 は q=0.12〜0.76 である。この事実は論文に明記し、α=0.05 依存であることを隠さない。
- α=0.10 を加える目的は (i) 効果の α 単調性により α=0.05 の合格が偶然でないことを裏づける、
  (ii) 流暢性が壊れる上限境界を押さえる。**ppl比の閾値 3.0 は維持**する（§6 M3）。
- **平均のCIと符号検定が食い違う場合は必ず両方を併記し、外れ値の影響と明記する。**
  片方のみの引用を禁じる。既知の該当例: 層7 α=0.01 の (a') は
  d=+3.801e−05・95%CI[−6.99e−06, +8.53e−05]（0を含む）でありながら Wilcoxon p=1.77e−03。

### 10.2 追加指標(i): 人間方向との整合スペクトルの全報告

各層・**全軸**について、人間の valence / arousal / dominance 方向との |cos| を表にする。

- 人間3方向は Warriner の V / A / D を目的変数とし、**最終トークン活性**から回帰して作る
  （`direction ∝ X^T y_z`、y は z 化、単位化）。**軸と同じプーリングに揃える**こと。
  平均プールは使わない（プーリング不一致が正の対照を壊した経緯があるため）。
- 刺激は発見群20件。フィット集合サイズをアサートし、無警告の縮小を禁じる（既定の D2 ガード）。
- **この |cos| を軸の選抜・並べ替え・除外に用いてはならない。** 記述としてのみ報告する。
  余弦で選抜すると、順序を変えるにせよ除外するにせよ人間の枠組みを基準に軸を定義することになり、
  「人間の枠外」という主張が同語反復になる（野村指示、既出の方針と同一）。

### 10.3 追加指標(ii): 人間VAD部分空間を除去した残差軸での介入（決定的検定）

各軸 a について、人間3方向 {v, a_r, d} が張る部分空間 S への射影を除去する:

```
P_S = Q Q^T   (Q = S の正規直交基底、Gram-Schmidt または QR で構成)
a_perp = a − P_S a ,  a_perp ← a_perp / ‖a_perp‖
```

`a_perp` に対し、生の軸と**完全に同一条件**で介入する（同一刺激・同一α・同一極性・
同一フック位置・同一乱数床）。実装上、`‖a − P_S a‖` が小さい軸（人間部分空間にほぼ含まれる軸）
では残差の方向が数値的に不安定になるため、**残差ノルム比 `‖a_perp_raw‖ / ‖a‖` を必ず記録**し、
0.1 未満の場合はその軸の残差結果を「数値的に不安定」として別扱いにする。

### 10.4 事前登録予測（データを見る前に記述）

- **R1**: 少なくとも1つの層に、生の軸が無作為床と直交床の両方を BH補正後 q<0.05 で上回り、
  **かつ残差軸 `a_perp` でも両床を q<0.05 で上回る**軸が存在する。
- **R2**: 層10の新軸1（人間valence方向との |cos| = 0.547 と既に判明している軸）は、
  残差軸で効果が**減衰**する。減衰の程度は事前に定めず、生の軸と残差軸の
  対応あり比較（Wilcoxon・ブートストラップCI・Cliff's δ）で報告する。
- **R3**: 人間VAD方向との |cos| が小さい軸ほど、残差化による JS の減衰率
  `1 − JS(a_perp)/JS(a)` が小さい（Spearman ρ > 0、全層プール、記述的検定）。

**反証と結論の対応**
- R1 が成立する軸が存在しない → 「再現性があり介入効果を持つ軸はすべて人間のVADの言い換えで
  説明できる」と結論する。論文2の中核主張は成立しない。**この結論をそのまま報告する。**
- R1 が成立する軸が存在する → その軸を列挙し、主張を §10.5 の形で述べる。
- R2 で層10新軸1の効果が残差化後も保たれる → 「|cos| が高くても人間VADの言い換えではない」
  という所見として報告する（R2 の予測が外れたことを明記する）。

### 10.5 主張の形（野村指示・確定）

**「すべての軸が人間の枠外にある」とは主張しない。** 主張は次の形に固定する。

> 再現性があり、介入で雑音床・直交床を超える効果を持ち、かつ人間の VAD 部分空間を
> 除去しても効果が残る軸が**存在する**。

- 全軸・全層で成立する必要はない（PI方針: 全モデルに一般化できなくても多くのモデルで良い）。
- **どの軸が人間の言い換えであり、どの軸がそうでないかを分離できること自体を結果として報告する。**
  人間の言い換えだった軸を隠さず、同じ表に載せる。

### 10.6 記録事項: 平均プール方向と軸の共線性は PAD 汚染の産物だった

- 旧軸（PAD汚染）: cos(平均プールpos方向, 旧軸0) = **−0.814**（層5）。
- 新軸（PADフリー）: 平均プールpos方向と全軸の **max|cos| = 0.112（層5）/ 0.122（層7）/
  0.086（層10）/ 0.082（層12）** と共線性は消滅。
- 一方、最終トークンpos方向は新軸と max|cos| = 0.100（層5）/ 0.139（層7）/
  **0.547（層10, 軸1）** / 0.334（層12）であり、層10・層12 では無視できない整合がある。
  これが §10.3 の残差軸検定を必要とする直接の理由である。

### 11.3 自己申告: M3（流暢性崩壊チェック）の測定が無効

実装した perplexity は `logits[0, :-1, :]` で `input_ids[1:]` を予測する teacher forcing だが、
**介入は最終トークン位置のみに加えている**。因果マスクにより、最終位置の隠れ状態は
位置 0..T−2 の予測に影響できず、最終位置の logits は ppl の計算対象から除外されている。
したがって **ppl比は構造的に必ず 1.00 になり、介入の影響を測っていない。**
全セルで pplR=1.00 だったのはこの人工物であり、流暢性が保たれた証拠ではない。

対処（第2段で実施。本節の R1 判定は ppl 条件に依存しないよう再集計する）:
- (a) 生成した継続テキスト上で ppl を測る（生成を伴うため第2段）、または
- (b) ppl 測定時のみフックを全位置に適用する、または
- (c) 介入位置の次トークン分布のエントロピー・top1確率を流暢性の代理指標とする（生成不要）。

**R1 の結論は ppl 条件を外しても変わらない**（12セルすべてで JS の条件のみで成立）。ただし
「流暢性が壊れていない」とは現時点では主張できない。

### 12.1 Q2: M3 の代替指標（承認済・生成不要）

ppl比は最終トークンのみの介入に対して構造的に不感であり（§11.3）、**1.00 は人工物**である。
**「流暢性が壊れていないことを確認した」とは書かない。** R1 が ppl 条件を外しても不変で
あった事実はそのまま記録する。代替として、**介入位置そのものの次トークン分布**から測る
（生成不要・構造的無効化が起きない）:

- `top1_prob`（介入後）とそのベースライン差
- `entropy_nats`（介入後）とベースライン比 `entropy_ratio = H_int / H_base`

**M3'（退化ガード、事前固定）**: 標本単位で以下のいずれかを満たすとき「退化」とする。
- `top1_prob ≥ 0.95`、または
- `entropy_ratio ≤ 0.5`、または
- `entropy_ratio ≥ 2.0`

セルの `degenerate_frac < 0.20` を満たす場合のみ、そのセルを効果あり候補として数える。
この閾値は結果を見る前に固定した。ppl比は参考値として出力を続けるが、**判定には使わない**
（無効であると分かっているため）。

### 12.2 Q3: 人間側部分空間の強化（3段構え）

**事前登録した3次元版（S1）を主判定として残す。** 後から人間側を増やして通ったものだけを
報告することは事後的な基準変更であり、行わない。全段の結果を必ず併記する。

| 段 | 人間方向の作り方 | 次元 | 位置づけ |
|---|---|---|---|
| **S1** | V/A/D を**発見群20件**から回帰（既実施） | 3 | **主判定（事前登録どおり）**。実効ランクを併記し限界を明記 |
| **S2** | V/A/D を**E1 300文**から回帰（同じ3次元・条件数のみ改善） | 3 | **強化副判定**。次元を増やさずに実効ランクを上げる |
| **S3** | S2 に**離散感情カテゴリ方向**を追加（E4 index 40–79 から one-vs-rest 回帰） | 3+20 | **最厳副判定**。実効ランクと残差ノルム比を必ず併記 |

すべて**最終トークン活性から回帰し、軸と同じプーリングに揃える**。

**S1 の限界（実測）**: 発見群20件では V/A/D が実質1方向に退化する。
特異値 [1.592,0.670,0.125]（層5）/ [1.612,0.618,0.143]（層7）/ [1.682,0.403,0.097]（層10）/
[1.671,0.439,0.118]（層12）、cos(V,D) = 0.978–0.989。**実効ランク（10%基準）= 1。**
したがって S1 の結果を「人間の枠組みを除去した」と書くことはできない。「人間valence方向を
実質1方向ぶん除去した」と書く。

**S2 が S1 より厳しい理由（実測・条件数診断より）**: E1 300文で回帰すると
特異値 [1.339,1.002,0.452]（層5）/ [1.340,1.000,0.452]（層7）/ [1.354,1.000,0.408]（層10）/
[1.364,0.998,0.381]（層12）、**実効ランク（10%基準）= 3**、参加比 2.51–2.60。
cos(V,A) = −0.006〜+0.050、cos(A,D) = −0.045〜+0.051 と**arousal が valence とほぼ直交**する。
すなわち退化は**刺激集合の性質**（E4テンプレートは感情語1語しか変わらないため V/A/D が共変する）
であって、モデルの性質ではない。cos(V,D) = 0.79–0.85 は E1 でも残るが、これは Warriner 規範
自体で valence と dominance が強く相関するという既知の性質と整合する。
**S2 は次元を1つも増やさずに実効ランクを1→3に上げるため、「次元を増やして結論を作った」
という批判を受けない。**

**S3 の扱い（野村注意点への対応）**: 人間側を無制限に増やせばどんな軸も残差ゼロに近づき、
必ず「言い換え」になる。よって S3 では以下を義務とする。
- 部分空間の特異値スペクトル・実効ランク（1%基準・10%基準・参加比）を必ず報告
- 各軸の残差ノルム比 `‖a−Pa‖/‖a‖` を必ず報告
- **結論は「何次元入れたか」ではなく「実効的に何方向除去したか」に基づいて述べる**
- S3 で効果が消えた場合、それが「人間の枠組みで説明できた」のか「部分空間が広すぎて
  何でも消える」のかを、実効ランクと残差ノルム比から判別して報告する。判別できない場合は
  「判別不能」と書く。

**カテゴリ方向を発見群から作らない理由（実測・空虚性の排除）**: 発見群20件は
**1カテゴリ1刺激**（20カテゴリ×1件）である。20カテゴリの one-vs-rest 指示ベクトルは
20標本上で R^20 を張るため、発見群活性の**行空間全体**を除去することになり、検定は
構成上空虚になる。よって S3 のカテゴリ方向は**E4 index 40–79**（どの介入実験にも使っておらず、
検証群でもない40件・20カテゴリ×2件）から作る。これには小さなGPUパスが必要
（40刺激×4層、数十秒）。

### 12.3 Q4: 人間 valence 方向そのものの効果（直接検定・生成不要）

§11.1 の仮説「人間VAD方向自体の次トークン分布への影響力が弱く、軸の人間成分が単位ノルムを
浪費している」を直接検定する。**人間 valence 方向を、軸と同一の刺激ごとの比で注入する**
（同一刺激・同一α・同一極性・同一フック位置・同一乱数床。単位ノルム）。

**事前登録予測（結果を見る前に記述）**
- **V1**: 人間 valence 方向の JS は、無作為床と**同程度**である。事前に「同程度」を
  次で定義する: 対応あり Wilcoxon（両側）で BH補正後 q ≥ 0.05、**かつ** |Cliff's δ| < 0.33。
- **V2**: 人間 valence 方向の JS は、上位3軸の JS を**下回る**（α=0.05、対応あり片側）。
- **V1 が成立** → 仮説（ノルムの浪費）を支持。残差化による増幅は、効果の弱い方向成分を
  除いて実効成分にノルムが集中した結果と解釈できる。
- **V1 が棄却され valence 方向が強い効果を持つ** → 仮説は不成立。増幅には別の説明が必要で、
  その場合は「説明不能」と書き、断定しない。

なお正の対照で測った pos 方向は α基準・比が今回と同一（刺激ごとの最終トークンノルム）なので、
**同一格子で再測定して軸と直接比較できる**。参考値として既に、層12 α=0.05 主条件で
pos 方向の JS=2.000e−03（無作為床 1.378e−03、比1.451）が得られている。
