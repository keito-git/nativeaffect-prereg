## 2. 最大の設計論点への回答: 「効果の大きさ」で選ぶのは誤り

野村先生の指摘のとおり、**効果量だけで選ぶと単に分散の大きい方向を選ぶ**ことになる。
論文2 の中心的知見が「**効果は方向の意味内容ではなく、方向が乗る部分空間の分散でほぼ決まる**」
（§35）なのだから、効果量による選抜は**その知見に真っ向から反する。**

### 2.1 提案する定式化: **分散プロファイルを揃えた床（profile-matched floor, PMF）**

in-plane 床は「上位10主成分の張る空間の内部」という**粗い**分散の揃え方であった。
これを**方向ごとに厳密化する。**

- 活性の主成分 `p_1 … p_K`（K は層ごとに固定、後述）とその固有値 `λ_1 … λ_K`
- 方向 `d` の**分散プロファイル** `c_k(d) = (d·p_k)²`（Σ_k c_k ≤ 1、残差は直交補空間）
- **PMF 乱択**: `c_k` を保ったまま方向を無作為化する。具体的には
  (i) 各 `p_k` 係数の**符号を無作為化**し、
  (ii) **固有値が近い主成分どうしで係数を無作為置換**し（固有値を対数等間隔でビン化）、
  (iii) 直交補空間の成分は、その補空間内で無作為に回転する
- **超過量** `E(d) = S(d) − mean_PMF S(d')`、標準化版 `z(d) = (S(d) − μ_PMF) / σ_PMF`

**PMF は in-plane 床の厳密な一般化である。** in-plane 床は「top-10 に入っているか否か」
だけを揃えるが、PMF は**どの主成分にどれだけ乗っているかの profile ごと**揃える。
**「その方向が乗る部分空間の分散から予測される効果を、どれだけ超えているか」**という
野村先生の要求を、モデル当てはめなしに実現する。

**非交渉事項2（基準は in-plane 床であって全空間床ではない）を満たす。**
PMF は in-plane 床より**厳しい**（分散の揃え方がより細かいため）。
**両方を報告する**（PMF を主、in-plane 床を副）。

### 2.2 選抜指標 S: **刺激をまたいだ出力変化の一貫性**

効果の**大きさ**ではなく**一貫性**で選ぶ。

> **ステアリング方向とは、入力が何であれ出力を同じ向きに動かす方向である。**
> 分散の大きい雑音方向は、出力を大きく動かすが、その動かし方は刺激ごとにばらばらである。

定義（α・層ごと）:

1. 刺激 `x_i` について、介入なしの次トークン分布 `p_i0` と `+αd` 注入時の `p_i+` を得る
2. **語彙集合 V を固定**（ベースライン質量の大きい上位 M 語の和集合。M は §5 で事前固定）
3. `Δ_i = log p_i+ − log p_i0`（V 上）。**`Δ_i` から平均を引いて中心化**する
   （大きさではなく「どの語に寄せたか」の contrast にするため）
4. **一貫性** `S(d) = mean_{i<j} cos(Δ_i, Δ_j)`

**これは方向不可知ではない。** JS は「どれだけ動いたか」しか見ないが、`S` は
「**同じ向きに動いたか**」を見る。§44 で指摘された成果指標の交絡に対する私の回答である。

**`S` は軸の意味を知らなくても計算できる。** 符号付き valence 読み出し（§46）は
POS/NEG 語彙を必要としたため語彙閾値に依存した（§47.4）が、`S` は**外部語彙を使わない。**
非交渉事項3（人間の方向との類似度で選抜しない）を構造的に満たす。

## 9. 改訂1（2026-09-26、野村指摘・**実行前**）: 中心化の軸を確定する

**§2.2 の「`Δ_i` から平均を引いて中心化する」はどの軸方向か書いていなかった。**
野村先生の指摘のとおり、**取り違えると指標が壊れる。** 実装前に確定させる。

### 9.1 確定: **語彙次元で、刺激ごとに中心化する**

```
Δ_i ← Δ_i − mean_over_V(Δ_i)      # 各刺激について、V 上の平均を引く
```

**必要な理由**: `log p` は正規化済みなので、logit 変化 `δ` に対し
`Δ = δ − [logsumexp(ℓ+) − logsumexp(ℓ0)]` となり、**刺激ごとに定数オフセットが乗る。**
余弦はこの定数を除去しないので、中心化しないと「どの語に寄せたか」ではなく
オフセットの大小を測ることになる。

### 9.2 **刺激次元での中心化は禁止する（指標が壊れる）**

```
Δ_i ← Δ_i − mean_over_i(Δ_i)      # 禁止
```

**理由（数学的）**: 我々が測りたい「入力が何であれ同じ向きに動かす成分」は
**まさに `mean_i Δ_i`** である。それを引いた残差 `r_i` は `Σ_i r_i = 0` を満たすので

```
0 = ||Σ_i r_i||² = Σ_i ||r_i||² + Σ_{i≠j} <r_i, r_j>
⇒ Σ_{i≠j} <r_i, r_j> = −Σ_i ||r_i||² < 0
```

**すなわち対の内積の和は方向によらず必ず負になる。** 測りたいものを除去した残りを測る
ことになり、**ppl が構造的に 1.00 に固定されていた件（§M3）、+α/−α の逆向き性が任意の
方向で自明に成立した件（§44.4）と同じ型の欠陥**である。

### 9.3 合成データでの確認（実装済み・実行済み）

`python/phase10/consistency_metric.py`。**本番関数そのものを合成データで駆動**した。
真の一貫方向を割合 `shared` で埋め込み、刺激ごとに無作為な倍率と定数オフセットを付けた。

| 検査 | 結果 |
|---|---|
| 一貫方向（shared=0.9）の S | **+0.988** |
| 無作為方向（shared=0.0）の S | **−0.006** |
| shared を 0→1 に上げたときの S | **0.00 → 0.11 → 0.51 → 0.90 → 1.00（単調増加）** |
| 刺激ごとの定数オフセットへの不変性 | 差 < 1e−9 |
| **刺激ごとの倍率への不変性** | 差 < 1e−9 |
| **刺激次元中心化（禁止版）の一貫方向 S** | **−0.047（負）** |
| **刺激次元中心化で一貫 vs 無作為を分離できるか** | **−0.047 対 −0.041。分離できない** |

**禁止版が構造的に負になり判別力を持たないことを実測で確認した。** 9.2 の数式どおりである。
本番関数は `centering="stimulus"` を**例外で拒否**する（取り違えを実行時に止める）。

### 9.4 **倍率不変性が設計の要である（重要）**

S は**刺激ごとの倍率に不変**である（上表）。したがって **S は効果の大きさを測っていない。**
これが「効果量で選ぶと分散の大きい方向を選ぶだけになる」（野村指摘）への構造的な回答である。
S が測るのは**シフトの形が刺激をまたいで揃っているか**だけである。

## 12. 改訂2（2026-09-26、**B0 実行前**）: 設計節への明記と、PMF 乱択数の精緻化

### 12.1 **S は効果の大きさを測らない（査読者が最初に疑う点・設計節に明記）**

§9.3 の実測で、**S は刺激ごとの倍率に不変**である（倍率を7倍にしても差 < 1e−9）。
したがって次が**定義上**成立する。

> **S は「どれだけ動かしたか」を一切含まない。刺激をまたいだシフトの形の一致だけを測る。**
> ゆえに「効果量で選抜すれば分散の大きい方向を選ぶだけになる」という批判は、
> **運用上の注意ではなく、指標の定義によって構造的に回避されている。**

**これは査読者が最初に疑う点である**（野村指摘）。**PMF と合わせて二重の防御**になっている。
PMF は「分散プロファイルから予測される水準」を差し引き、S は「大きさ」を最初から見ない。

### 12.2 PMF 乱択数を B0 に限り **20 → 100** に増やす（**実行前に宣言**）

§5 で PMF 乱択数を 20 draws/方向と固定したが、**B0 の p 値の分解能が 1/20 = 0.05 となり、
BH q<0.05 を判定できない。** 実測（論文2 の run）から順伝播は約50回/秒であり、
100 draws でも 4層×4α×20刺激×100 ≈ 32,000 回 ≒ 11分で収まる。

- **B0 に限り 100 draws** とする。**規準を緩めない**（p の分解能が上がるだけで、
  むしろ厳しい側に働く）
- **B1・B2 は §5 のとおり 20 draws** のまま（B1 は順位付けのみで床を使わない、
  B2 は選抜後の少数方向のみなので、必要なら別途宣言して増やす）

### 12.3 B0 の検定手続き（実行前に確定）

- **S は +α 極性で計算する**（criterion）。−α は陽性対照についてのみ**記述的に併記**する
  （判定には使わない）
- **p 値**: `p = (1 + #{PMF draws with S ≥ S(pos)}) / (1 + n_draws)`（permutation 流の
  保守的な定義。0 にならない）
- **BH 族**: 4層 × 4α = **16検定**
- **効果の記述**: `E = S(pos) − mean_PMF(S)`、および `z = (S(pos) − μ) / σ`
- **ブートストラップ**: 刺激を再抽出（10,000回・seed 20260925）して `S(pos)` の 95% CI
- **合格規準（§3 のとおり）**: α=0.05 で **4層中3層以上**が BH q<0.05 かつ E>0
