## 1. 何を試みるか

PI 構想（2026-09-22）の因果部分「**その概念に適切に介入することで AI の感情的な振る舞いを
操作できる**」を回復する試み。

**現行の軸が失敗した理由は特定済みである。** 軸の選抜が「活性の分割半々での再現性」だけで、
**出力への効果を一切見ていなかった。** 論文2 で得た手がかりは2つ。

1. 分割をまたいで**効果量を伴って**再現する軸が3行（層5軸2・層7軸1・層12軸0）。
   層5軸2 は両群 α=0.05 で in-plane 床を超え、検証群で効果量が増大（δ +0.25→+0.55）
2. 符号付き指標でも一部の軸が床を上回る（層7軸1・軸2 で δ=+1.00 など。§47.5、未登録の探索）

**すなわち、出力を見ない選抜でも偶然混ざる程度には存在する。狙って選べば増える可能性がある。**

## 2. 最大の設計論点への回答: 「効果の大きさ」で選ぶのは誤り

野村先生の指摘のとおり、**効果量だけで選ぶと単に分散の大きい方向を選ぶ**ことになる。
論文2 の中心的知見が「**効果は方向の意味内容ではなく、方向が乗る部分空間の分散でほぼ決まる**」
（§35）なのだから、効果量による選抜は**その知見に真っ向から反する。**

### 2.1 提案する定式化: **分散プロファイルを揃えた床（profile-matched floor, PMF）**

in-plane 床は「上位10主成分の張る空間の内部」という**粗い**分散の揃え方であった。
これを**方向ごとに厳密化する。**

- 活性の主成分 `p_1 … p_K`（K は層ごとに固定、後述）とその固有値 `λ_1 … λ_K`
- 方向 `d` の**分散プロファイル** `c_k(d) = (d·p_k)²`（Σ_k c_k ≤ 1、残差は直交補空間）
- **PMF 乱択**: `c_k` を保ったまま方向を無作為化する。具体的には
  (i) 各 `p_k` 係数の**符号を無作為化**し、
  (ii) **固有値が近い主成分どうしで係数を無作為置換**し（固有値を対数等間隔でビン化）、
  (iii) 直交補空間の成分は、その補空間内で無作為に回転する
- **超過量** `E(d) = S(d) − mean_PMF S(d')`、標準化版 `z(d) = (S(d) − μ_PMF) / σ_PMF`

**PMF は in-plane 床の厳密な一般化である。** in-plane 床は「top-10 に入っているか否か」
だけを揃えるが、PMF は**どの主成分にどれだけ乗っているかの profile ごと**揃える。
**「その方向が乗る部分空間の分散から予測される効果を、どれだけ超えているか」**という
野村先生の要求を、モデル当てはめなしに実現する。

**非交渉事項2（基準は in-plane 床であって全空間床ではない）を満たす。**
PMF は in-plane 床より**厳しい**（分散の揃え方がより細かいため）。
**両方を報告する**（PMF を主、in-plane 床を副）。

### 2.2 選抜指標 S: **刺激をまたいだ出力変化の一貫性**

効果の**大きさ**ではなく**一貫性**で選ぶ。

> **ステアリング方向とは、入力が何であれ出力を同じ向きに動かす方向である。**
> 分散の大きい雑音方向は、出力を大きく動かすが、その動かし方は刺激ごとにばらばらである。

定義（α・層ごと）:

1. 刺激 `x_i` について、介入なしの次トークン分布 `p_i0` と `+αd` 注入時の `p_i+` を得る
2. **語彙集合 V を固定**（ベースライン質量の大きい上位 M 語の和集合。M は §5 で事前固定）
3. `Δ_i = log p_i+ − log p_i0`（V 上）。**`Δ_i` から平均を引いて中心化**する
   （大きさではなく「どの語に寄せたか」の contrast にするため）
4. **一貫性** `S(d) = mean_{i<j} cos(Δ_i, Δ_j)`

**これは方向不可知ではない。** JS は「どれだけ動いたか」しか見ないが、`S` は
「**同じ向きに動いたか**」を見る。§44 で指摘された成果指標の交絡に対する私の回答である。

**`S` は軸の意味を知らなくても計算できる。** 符号付き valence 読み出し（§46）は
POS/NEG 語彙を必要としたため語彙閾値に依存した（§47.4）が、`S` は**外部語彙を使わない。**
非交渉事項3（人間の方向との類似度で選抜しない）を構造的に満たす。

## 3. 段階と、各段階の停止条件

### Phase B0: **指標の検証（選抜より前・失敗したら B は停止）**

**非交渉事項4: 選抜に使う指標そのもので陽性対照を通す。**

- 陽性対照 = 人間 valence 方向（`regress_dir` ではなく **P2_ridge_std**。§23 で切替済み）
- **合格規準（事前固定）**: **4層中3層以上**で、陽性対照の `z(d)` が
  **PMF に対して BH q<0.05 かつ E(d)>0**。α は §5 の水準、判定は α=0.05
- **不合格なら B を停止し、「一貫性指標は意味内容が既知の方向すら検出しない」と報告する。**
  言い換えで救わない

**予測（中村）**: 通る確率 60%。根拠は §47.2 で符号付き指標では層5・7 が in-plane 床を
明確に上回ったこと（δ +0.70 / +1.00）。ただし `S` は語彙を使わないので弱くなる可能性がある。
**層10 は §47.3 の符号反転があるため通らないと予測する。**

### Phase B1: 選抜（選抜集合のみ）

- 候補 = **各層の ICA 成分すべて**（top-3 に限定しない。K は層ごとに 5〜20）
- 各候補の `z(d)` を**選抜集合**で計算し、**上位 n_sel = 3 本/層**を選ぶ
- **選抜に検定は使わない**（選抜は順位付けのみ。p 値は検定集合でのみ解釈する）

### Phase B2: 検定（検定集合のみ・1回だけ）

- B1 で選んだ軸について、**検定集合**で `E(d)` を PMF に対して検定
- **合格規準（事前固定）**: **4層×3軸=12セル中4セル以上**で BH q<0.05 かつ E(d)>0
  （α=0.05、BH 族 = 12セル×α4水準 = 48）
- 副次: in-plane 床に対しても同じ検定を報告する

### Phase B3（**今回は実行しない**）: 軸が何を表しているかの記述

床を超える軸が確定してから着手する。**人間の枠組みを使わない記述法**が必要で、
設計してあった応答空間反転（v7）は dry-run 規模のまま帰無検定も無効だったので**作り直し**。
**本事前登録では「第2段階として軸の記述を行う」ことだけを宣言する。**

- **分割規則は論文2 と同一**: カテゴリ層化。各カテゴリの2変種を片方ずつ、
  **選抜集合20 / 検定集合20** に割り当てる。seed は本事前登録の commit 時刻から固定
- **活性は既にキャッシュ済み**（`e4_heldout40to79_seed0042.npz`、4層×40×2048）。
  ただし**介入は GPU が必要**

**注意して記録する**: 40–79 のカテゴリは 0–39 と**異なる**（0–39 は正10・負10 で均衡、

**したがって B の結果を論文2 の結果と直接比較しない。** 比較する場合は
