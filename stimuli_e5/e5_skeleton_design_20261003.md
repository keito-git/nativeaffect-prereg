# E5 再設計：シナリオ骨格 × カテゴリの格子

**作成**: 2026-10-03
**経緯**: 鬼頭の赤チーム査読により、自由記述型のパイロット24文は本番不可と判定。
24文中6文が構造的欠陥（ドメイン交絡・カテゴリ越境・経験者不在）、4文が語彙漏れ。

## 何が問題だったか

E4 の批判は「**感情語**のトークン表現を測っているだけ」であった。
自由記述型の E5 は、それを「感情語を含まない状況記述」で回避しようとした。

しかし **LLM は訓練コーパスにある文化的な物語の型にも感応する**。
「治療後の検査結果が陰性 → joy の物語」「医師が結果を対面で説明したいと連絡 → anxiety の物語」。
**語からシナリオへ、抽象化のレベルが1段上がっただけで、問題の構造は同じである。**

E4 と E5 で結果が一致しても「語彙統計とシナリオ統計が相関していた」と再解釈されうる。

## 解決：シナリオを対照として固定する

**同一のシナリオ骨格に対して、複数の感情カテゴリの版を書く。**
骨格を固定し、感情だけを動かす。これで「話題を測っているだけ」を構造的に排除する。

本研究群がずっと使ってきた原理——**検定したくないものを対照で固定する**——を刺激設計に
適用したものである。VMIC が分散を固定したのと同じ構造。

### 格子の形

骨格 $s \in \{1..m\}$、カテゴリ $k \in \{1..40\}$ に対し、文 $x_{sk}$ を書く。
全セルが埋まる必要はない（骨格によっては書けないカテゴリがある）。

分析では **骨格内でカテゴリを比較する**。骨格間の差は交絡として扱い、
骨格を固定効果として除く。

### 骨格の条件

1. **感情的に中立な出来事の型**であること。骨格の名前自体が感情を含意しない
2. **複数のカテゴリの版が書ける**こと（最低4カテゴリ）
3. **ドメインが互いに重ならない**こと（医療・学術・対人・職業・日常・移動…）
4. 骨格ごとに**経験者（protagonist）が明示される**こと（鬼頭 指摘7）

## 骨格の初期案（10件）

| # | 骨格 | 中立な記述 | 書けるカテゴリの例 |
|---|---|---|---|
| 1 | 検査結果の受領 | 医療検査の結果が本人に届く | joyful / anxious / relieved / dejected / terrified |
| 2 | 選考の通知 | 応募に対する可否が通知される | elated / dejected / anxious / relieved / disappointed |
| 3 | 旧居の訪問 | かつて住んだ場所を再訪する | melancholic / nostalgic / sad / content |
| 4 | 予定外の遅延 | 移動中に予定が崩れる | anxious / frustrated / calm / bored |
| 5 | 他者の成果を知る | 知人の達成を知る | envious / jealous / proud / grateful |
| 6 | 作業中の異常 | 手順の途中で想定外が起きる | curious / confused / panicked / anxious |
| 7 | 久しぶりの再会 | 長く会っていない相手と会う | joyful / loved / melancholic / embarrassed |
| 8 | 自分の過失の発覚 | 自分の誤りが他者に知られる | ashamed / guilty / embarrassed / dejected |
| 9 | 長い待機の終了 | 待っていた事柄に決着がつく | relieved / satisfied / hopeless / ecstatic |
| 10 | 規範からの逸脱を目撃 | 他者の振る舞いが基準を外れる | disgusted / contemptuous / furious / surprised |

骨格は**感情ではなく出来事の構造**で定義してある。各骨格で同一の登場人物・同一の場面設定を
用い、**結末と含意だけを変える**。

## 書き方の規則（村田の仕様に追加）

- 骨格内の全版で、**主語・場面・時制の骨格を共有**する。変えるのは結末と含意のみ
- 骨格内で**語数を ±2 語以内**に揃える
- 感情状態を直接記述する句を禁止（`the crowd erupted` `could not retain` `without any
  explanation` のような、形態素一致では捕まらないが働きは感情語と同じもの）
- 経験者を必ず明示する

## 残る限界（論文に明記する）

**シナリオ水準の prior を完全には統制できない。** 骨格を固定しても、結末の記述自体が
物語の型を呼ぶ可能性は残る。E4 と E5 の一致は「**語水準の感情語では説明できない範囲まで
再現された**」という限定された主張に留める。鬼頭の勧告に従う。

## 次の手順

1. 骨格10件それぞれについて、4カテゴリ以上の版を書く（パイロット：骨格3件 × 4カテゴリ = 12文）
2. 語彙漏れの機械スキャン（WordNet 派生展開）
3. NLI 3モデルで Δ≥0.15 の分離条件を確認
4. 合格後に全骨格へ展開
