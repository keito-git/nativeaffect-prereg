# 事前登録 追記4：B3-a の前提が先行研究と逆だった。仮説の向きを実験前に訂正する

**対象**: 追記2 の B3-a（人間VAD方向との対比）、追記3 の C4
**作成**: 2026-09-26
**状態**: **実験前。** push 前
**典拠**: `01_調査/採択手法の先行性調査_20260926.md` の追記（文献担当・E-STEER 全文確認 ○）

## D1. 何が間違っていたか

追記2 の B3-a で、私は次を期待すると書いた。

> 人間の感情は認知を歪めるので、arousal を上げれば速くなるが誤る、という結果が期待される。
> **軸Xでは落ちないなら、「人間の枠外だからこそ副作用がない」という主張の型になる。**

**この期待は先行研究と逆である。**

E-STEER（arXiv:2604.00005）の全文に、**人間の VAD 方向への活性介入が推論精度を改善する**と報告されている（文献担当が全文で確認、原文引用あり）。

- 中程度の valence 状態で中立比 **平均 +3.4%**
- dominance 方向で **最大 +14.5%**
- 極端な状態では悪化: 過剰な活性化は推論を早期に打ち切らせる

**すなわち逆U字（非単調）であり、「感情介入は精度を悪化させる」という知見ではない。**

**したがって「人間の枠外だからこそ副作用がない」という主張の型は成立しない。** 人間の軸にも（中程度では）副作用どころか改善がある。

## D2. 仮説をどう置き換えるか

**捨てる主張**: 人間軸への介入は精度を落とすが我々の軸は落とさない。

**置き換える主張（実験前に固定する）**: **人間の VAD 方向は精度を改善するが、それは計算量の削減を伴わない。我々の軸は精度と計算量の前線そのものを動かす。**

根拠となる事実の切り分け:
- E-STEER は**精度**を測っているが、**トークン数・計算量を測っていない**（文献担当の全文確認の範囲）
- したがって「人間の軸が精度／トークンの前線を動かすか」は**未報告**である
- **我々の比較対象はここになる**

**改訂後の B3-a**:
1. 人間 VAD 3方向について、**係数を掃いて精度とトークン数の両方を測る**。E-STEER の逆U字を我々の環境で再現できるかを確認する（**再現できなければ再現できなかったと報告する**）
2. 同じ測定を軸Xについて行う
3. **精度対トークン数の平面に両者の曲線を描き、前線の位置を比較する**
4. 判定: **軸Xの曲線が人間VAD 3方向すべての曲線より上（同一トークン数で高精度、または同一精度で低トークン）にある区間が存在するか**

**事前に決める判定基準**: 主要ベンチマーク1件で、**軸Xの前線が人間VAD の3本すべてを、トークン数の少なくとも3分の1以上の区間で上回る**。対応のあるブートストラップ（2000回）の95%CIが0を跨がないこと。

**落ちたら**: 「人間の軸と我々の軸は精度／計算量の前線において区別できない」と記録する。**その場合、追記2 の中心主張（概念は計算の配分で定義される）は支持されない。** 言い換えずに書く。

## D3. E-STEER の扱い

- **必ず引用する。** 感情の活性介入が推論精度を動かすことを示した先行として
- **逆U字（中程度で改善・過剰で悪化）を正しく記述する。** 「感情介入は推論を悪化させる」と書いてはならない。**原文はそう言っていない**
- 我々の差分は2点に限定する: (a) **計算量を測ること**、(b) **人間の VAD 軸ではない軸を使うこと**
- E-STEER が VAD 軸のみを使い**異なる軸を比較する実験設計を持たない**ことは文献担当が全文で確認した。**したがって軸の対比自体は独立である。ただし「我々の知る限り」を付ける**

## D4. この訂正が意味すること（正直に記録する）

**追記2 で立てた最重要実験の期待の向きが、先行研究と逆だった。** 原因は、私が「人間の感情は認知を歪める」という常識を、先行研究を確認せずに仮説の根拠に使ったことである。
**文献担当に全文確認を指示したのは実験前であり、走る前に分かった。** 走った後に分かっていれば、逆U字を知らずに「人間軸は悪化する」と書いた原稿ができていた。

**再発防止**: 仮説の向きを決める前に、その向きを主張する先行研究を1本は確認する。**常識を根拠にしない。**

## D5. 動機づけの差分は全文で裏付けられた（追記3 C1 の確定）

等長介入4件の全文を文献担当が確認した。動機は順に、層ノルム変動への係数感度／正規化層での分布シフト蓄積／スケールと能力保持のトレードオフ／表現空間逸脱による生成品質悪化。
**「加算介入の効果が方向の高分散空間への帰属と交絡する」という問題意識は4件のいずれにもない。**

**したがって追記3 C1 の「動機づけの差分のみ主張する」は全文確認で裏付けられた。** この差分は書いてよい。
