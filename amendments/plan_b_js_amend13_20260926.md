## M2. 決定：E1 に分割を定義する。判定を計算する前に

**「再分割しない」という §3 の規定は、既存の分割を作り直さないという意味である。存在しない分割を新たに定義することは再分割ではない。** そのうえで、恣意を入れないために規則を先に固定する。

**分割の規則（結果を1つも見る前に固定する）**:

1. **対象 = VAD スコアを持つ E1 の 287 文**
2. **層化 = Warriner 規範から得た valence の三分位**（低・中・高）。各層内で無作為割り付け
3. **比率 = 50/50。**端数は発見群に寄せる（143 / 144）
4. **シード = 20260926**、`numpy.random.default_rng` を使用、**抽出された ID を JSON に記録**
5. **出力 = `03_解析/plan_b/e1_split_20260926.json`。** `defined_before_any_G1_judgement: true` を明記

**valence で層化する理由**: 判定に使う量が出力分布の変化であり、valence は刺激の感情的性質のうち最も強く出力に効く軸だからである。**層化せずに割ると、片方の群に極端な valence が偏り、群間の比較が刺激の性質の差を反映しうる。**

## M3. 候補方向の計算も発見群に限る（重要）

**これが今回の停止の実質的な理由である。**

**ICA 成分・上位10主成分・ヤコビアン感度方向のいずれも、発見群（143文）の活性からのみ計算する。**

- 287文すべてから計算すると、**検証群のデータが候補の選抜に入る。** 発見/検証分割の目的が失われる
- **PMF 床の基底も発見群から作る**
- **G1 の判定は発見群で行う。** G2 で検証群を開封し、G1 を通ったセルが再現するかを見る

**現在走らせているヤコビアン計算は287文を対象にしているため、停止して発見群143文で作り直す。** 判定統計量は1つも計算していないので、**開封には当たらない。**

**費用は減る**: 287 → 143 で、ヤコビアンは 2.87時間 → 約1.43時間。
