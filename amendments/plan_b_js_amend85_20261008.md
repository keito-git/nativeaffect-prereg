## CD1. 答えるべき反論

> 感情カテゴリ方向は感情カテゴリのラベルから作り、評価も感情カテゴリ語の次トークン確率で
> 行っている。両側で同じオントロジーを使っているから勝つのではないか。

これが現在の最大の代替説明である。追記82 の同義語群読み出し（R-syn）はこれに答えない。
同じ13カテゴリの語彙である。

### 反論の核は語彙である

感情方向は、活性空間で13カテゴリのラベルを分離するように推定している。
読み出しは**その語そのもののトークン確率**である。したがって
「`anger` というトークンの logit を上げるだけの方向」は、
表現についての主張を何も伴わずに勝てる。

**断つべきは語彙の一致である。** 読み出しに感情語を一切含めない。

## CD2. R-act（行動傾向読み出し）の仕様

### 枠組み

プロンプトの枠を変え、**感情語を含まない13個の動詞**の次トークン確率で読み出す。

```
Event: {text}

The person's immediate impulse is to
```

**この枠に感情語は現れない。** 現行の枠（`The emotion is`）とは別経路である。

### 対応表（本追記で固定する。結果を見てから変更しない）

| カテゴリ | 動詞 | カテゴリ | 動詞 |
|---|---|---|---|
| anger | fight | pride | boast |
| boredom | yawn | relief | relax |
| disgust | spit | sadness | cry |
| fear | flee | shame | blush |
| guilt | confess | surprise | gasp |
| joy | celebrate | trust | rely |
| no-emotion | continue | | |

**13個の動詞のいずれも感情カテゴリ名ではなく、その同義語でもない。**

### 読み出しの計算

現行と同一である。介入前後の次トークン確率の差を13動詞のトークンについて取り、
中心化し、単位ノルムに正規化し、符号付きにする。**統計量も一切変更しない。**

トークン ID は追記84 の修正済み規則（復号して文字が残る最初のトークン）で取り、
**クラス間で重複したら異常終了させる。**

### 校正

介入強度は現行と同一の全語彙 JSD で揃える。$J^\ast = 0.05$。
**校正は読み出しに依存しないため、R-single・R-syn と同一の $\alpha$ になる。**
ただしプロンプトの枠が違うため、$\alpha$ は枠ごとに再校正する。

## CD3. 妥当性の事前検査（判定の前に行う）

対応表が恣意的であってはならない。**判定の前に次を測り、満たさなければ R-act を用いない。**

1. **識別性**：介入なしの状態で、13動詞の次トークン確率が退化していないこと
   （異なる値が10以上、標準偏差 > 0）
2. **対応の妥当性**：crowd-enVENT の各カテゴリの刺激について、
   当該カテゴリの動詞が13動詞中で最も高い確率を持つ割合（最頻一致率）を測る。
   **13カテゴリの過半で最頻一致すること**を要求する
3. **語彙の非重複**：13動詞のトークン ID が互いに異なること

**2 を満たさない場合**：対応表が機能していない。
**その場合、R-act を「対応表が機能しない」と記録し、別の独立読み出しを追記86 で設計する。
対応表を結果が良くなるように書き換えることはしない。**

## CD6. この読み出しが答えないこと

R-act は**語彙の循環性**を断つが、**カテゴリの目録そのもの**は人間由来の13カテゴリである。
「13カテゴリという区切り方が特権的か」は別の問いであり、R-act では答えない。
**本追記ではこの限界を明記したうえで、語彙の循環性に限って反論を潰す。**

さらに、**対応表（感情→動詞）は私が作ったものであり、独立に検証された写像ではない。**
CD3 の最頻一致率はその妥当性の検査だが、写像の正しさを保証するものではない。
**この点を限界として本文に書く。**
