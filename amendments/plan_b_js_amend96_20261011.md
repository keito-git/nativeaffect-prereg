# 事前登録 追記96：語彙構造では復号可能性を揃えられない。活性クラスタで上から揃える

**作成**: 2026-10-11
**対象**: 追記91 CJ3 の構造整合分割対照（SP）
**判定**: **語彙クラスタでは許容帯に入る分割が得られない。登録どおり「得られなかった」と報告し、
代わりに復号可能性が感情分割を上回る対照を新たに登録する。**
**起動条件**: 本ファイルを commit し push したあとでなければ新しい対照を判定しない。

---

## CO1. 語彙クラスタでは届かない（実測）

追記91 CJ3 は、文字 n-gram の TF-IDF から作ったクラスタをクラスサイズを揃えて用い、
**保持集合でのプローブ AUC が感情分割の ±0.05 に入る引きのみ採用**すると登録していた。

Llama-3.2-1B（層12）での実測：

| 量 | 値 |
|---|---|
| 感情分割の保持 AUC 中央 | **0.9546** |
| 語彙クラスタ候補の AUC 範囲（200本評価） | **0.5148 〜 0.8813** |
| 許容帯 | 0.9046 〜 1.0 |
| 採用された分割 | **0 本** |

**語彙構造から作れる分割の復号可能性の上限は 0.8813 であり、感情分割の 0.9546 に届かない。**
復号可能性を下げるノブ（無作為再割当）は用意したが、**上げる手段がない。**

### これは報告すべき知見である

> **人間の感情分割は、同一粒度・同一クラスサイズのどの語彙構造分割よりも、
> モデルの活性から復号しやすい。** 200本の候補の最大が 0.881、感情分割が 0.955 である。

**追記91 CJ3 の約束どおり「許容帯に入る分割が得られなかった」と報告する。
ノブや許容帯を緩めて無理に採用しない。**

## CO2. 新しい対照 SP-act（活性クラスタ・復号可能性を上から揃える）

### 発想

復号可能性を**揃える**ことができないなら、**上回る**対照を置けばよい。
感情分割より復号しやすい分割に対して感情分割が介入効果で勝つなら、
**「予測可能な分割だから効いた」という説明は成立しない。**

### 構成（本追記で固定する。結果を見る前に定義する）

1. 学習行の活性 $X_{\mathrm{fit}}$ を標準化した空間で $k=13$ の k-means を実行する
2. クラスサイズを感情分割に合わせる（追記91 CJ3 と同一の貪欲移送）
3. 得られた13分割の指示変数に、**感情族と完全に同一の手続き**でリッジ方向を当てる
4. 保持集合でのプローブ AUC を測り、**感情分割の AUC 以上**であることを確認する。
   下回る引きは採用しない
5. 30本採用するまで繰り返す（k-means の初期値・部分空間次元を変える。上限200試行）

**感情ラベルは一切用いない。** 活性のクラスタ構造のみを用いる。

### 循環性についての明示

**活性クラスタは、活性から復号しやすいのが当然である。** それが狙いである。
この対照は「感情分割が最も復号しやすい分割である」ことを主張するためのものではなく、
**「復号しやすさでは介入効果を説明できない」ことを示すためのもの**である。
したがって対照側が有利であることは設計上の意図であり、**保守的な対照**である。

### 判定 SP-act（結果を見る前に固定する）

感情族が、活性クラスタ族30本の族最良を超えるか。
**合格条件**：13標的の過半を超え、かつ $p_G<0.05$（30本のため）。**モデルの過半**で満たすこと。

| 判定 SP-act | 書けること |
|---|---|
| 合格 | **復号可能性では説明できない。** 感情分割より復号しやすい分割に対しても感情分割が勝つ。**追記90 の主張を「恣意的な分割を上回る」から「復号可能性で説明されない」へ強められる** |
| 不合格 | **復号可能性で説明できる可能性が残る。** 追記90 の主張は「クラスサイズを揃えた恣意的な分割を上回る」に留める。**それ以上の主張をしない** |

**不合格でもそのまま報告する。**

### 併せて報告する

採用した活性クラスタ分割の AUC 中央と範囲、感情分割の AUC、却下した試行数を表に載せる。
**対照側の AUC が感情分割を上回っていることを数値で示す。**

## CO3. 語彙クラスタの結果も捨てない

語彙クラスタは許容帯に入らなかったが、**最も復号しやすい30本**（AUC 上位）を
**補助的な対照**として測定する。AUC は 0.85〜0.88 程度であり感情分割より低いが、
無作為分割（0.51）よりはるかに高い。

**この補助対照は判定に用いない。** 「復号可能性 0.88 の分割に対しても勝つか」という
記述的な情報として報告する。**判定は SP-act で行う。**

## CO5. 約束

- 語彙クラスタで許容帯に入る分割が得られなかったことを、そのまま報告する
- 許容帯もノブも緩めない
- SP-act の対照側 AUC が感情分割を上回っていることを数値で示す
- **SP-act が不合格なら、追記90 の主張を「恣意的な分割を上回る」に留める**
- 語彙クラスタの補助測定を判定に用いない
- 「感情分割が最も復号しやすい」という CO1 の知見を、介入効果の主張と混同しない
