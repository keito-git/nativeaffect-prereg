## Q1. 欠陥1：登録した引き方では、軸の残差が外挿になる

追記14 N5 はこう規定した。

> 各層で、**上位主成分部分空間の内部から無作為方向を1,000本**引く

**内部から引くと inside_fraction は構成上すべて 1.0 である。** ところが**軸の inside_fraction は 0.2〜0.3 程度**である。

**したがって1,000本で当てた回帰を軸に適用すると外挿になり、残差は「軸が分散の予測どおりに振る舞うか」ではなく「モデルが訓練範囲外でどれだけ外れるか」を部分的に測る。**

**これは私が登録した設計の欠陥である。**

### 決定

**主解析は登録どおり `in_span`（部分空間内部から1,000本）のまま変えない。** これは「**優勢分散部分空間の内部にある方向の間では、射影プロファイルが JS を予測するか**」という問いに答える。それ自体で成立する問いである。

**加えて `coverage` の引き方を実行する。** $d = \sqrt{f}\,u_{in} + \sqrt{1-f}\,u_{out}$ により inside_fraction を厳密に $f$ にでき、**観測された inside_fraction の範囲を覆うように引ける。**

**軸と人間 valence 方向の残差を解釈するのは `coverage` の結果に対してのみ行う。** `in_span` の結果に対しては**残差を解釈しない。**

**`in_span` で軸の残差を報告する場合は、「参照方向の inside_fraction が訓練範囲外であるため、この残差は外挿を含み解釈しない」と明記する。** 実験担当が実装した旗（訓練範囲外なら解釈を拒否）をそのまま使う。

**両方の結果を報告する。** どちらか良い方を選ばない。

## Q2. 欠陥2：弱い推定器の失敗を「意味の寄与」と読み替えてしまう

実験担当が**厳密な線形関数**を対象に推定器を校正した（到達可能な $R^2$ は 1）。

| n | 線形モデル | 勾配ブースティング | 不足 |
|---|---|---|---|
| 200 | 1.0000 | 0.8426 | 0.1574 |
| 400 | 1.0000 | 0.8485 | 0.1515 |
| **1,000（登録値）** | **1.0000** | **0.9197** | **0.0803** |

**登録したサンプル数でも、厳密に予測可能な対象に対してブースティングは 0.92 しか出さない。** その数値を答えとして読むと、**推定器の誤差 0.08 を「方向の意味の寄与」に読み替える。**

**逆方向も確認済み**: 符号（＝意味）で決まる対象では、n=1,000 で報告値 **−0.0019**。**意味が効く場合はきちんと 0 付近になる。**

### 決定

**報告値 = 線形とブースティングの良い方（最大）とする。**

**理由**: N5 が問うのは「射影プロファイルで JS を予測**できる**か」である。**弱い推定器が失敗したことは「できない」の証拠にならない。** 到達可能な予測可能性を推定するには、試した推定器の最大を取るのが正しい操作化である。

**ただし3つの条件を課す。**

1. **両方の値を常に併記する。** 最大値だけを書かない
2. **中népen村の校正表（上表）を報告に添える。** n=1,000 での各推定器の天井が読者に分かる形にする
3. **非対称性を明記する。** 最大を取ることは**予測可能性の上側の推定**であり、「方向の意味が効く」という主張に対しては保守的だが、「**意味は効かない」という主張に対しては非保守的**である。**この非対称性を本文に書く**

**3 を課す理由**: 追記15 で機構の説明を取り下げたので、**N5 の $R^2$ は「説明を与えない測定値」として報告される。** どちらの方向にも主張がないので、最大を取ることが自己都合にならない。**しかし将来この数値を引用して何かを主張するとき、非対称性が記録されていなければ誤用される。**

## Q4. 記録：JS の実装が9本あり、互いに比較されていた

**実験担当が、9本のスクリプトがそれぞれ独自に次トークン JS を定義していたことを発見した**（関数名3種・キー綴り2種、ソースとして4変種）。**そして異なるスクリプトの結果が互いに比較されてきた。**

**9本すべてを抽出し同一入力で実行して、最大差 0.000e+00 を確認した。** 解析的な錨とも一致（同一分布で 0、互いに素で $\ln 2 = 0.693147180560$）。`top_k = 100`・`max_len = 128` も全9本で同一。

**したがって過去のスクリプト横断比較は、この軸では有効である。**

**もし2本でも違っていれば、B0・E1診断・C1〜C4 の間の比較が比較でなかったことになっていた。** 読んで同じに見えることは証明ではない。

**今後の規則**: **同じ量を計算する関数を複製しない。** 複製が既にある場合は、**同一入力での一致を数値で確認してから比較に使う。**
