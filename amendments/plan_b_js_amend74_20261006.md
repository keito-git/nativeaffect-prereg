# 感情カテゴリ軸は効率的であり、評価軸は床と区別できない

**作成**: 2026-10-06
**対象**: 追記73 の判定 E5
**判定**: **E5-pre 成立。E5a 不成立。** 追記73 BV6 の約束どおり、H1 を介入効率について修正する。
**実施**: Llama-3.2-1B（L12）。他モデルへの拡張を実行中。

## BW1. 結果（Llama-3.2-1B・$d$=2048・3予算）

保留文脈での効率が床の95パーセンタイルを超えた目標の数を示す。床自身の値は、21本から
選抜用文脈で最良を選び保留で評価したものであり、選抜による上振れを含む。

| 族 | $J^\*$=0.02 | 0.05 | 0.10 |
|---|---|---|---|
| **e 勾配方向（正の対照）** | **13/13** | **13/13** | **13/13** |
| **a 感情カテゴリ方向** | **12/13** | **12/13** | **12/13** |
| c 主成分方向 | 7/13 | 8/13 | 9/13 |
| d 分散整合無作為（床・自身の選抜最良） | 3/13 | 8/13 | 5/13 |
| **b 評価次元方向** | **3/13** | **2/13** | **3/13** |

## BW2. E5-pre が初めて通った

**勾配方向が3予算すべてで13/13である。** 本研究群で**正の対照が明確に通った最初の判定**である。

追記58・59・61 では Warriner valence 方向を正の対照に用い、4モデル中3モデルで床に届かず
判定不能が続いた。**原因は読み出しの鈍さではなく、正の対照の選び方であった。**
valence ノルムへの回帰方向は、感情カテゴリ出力を動かす方向として最適ではない。
勾配方向は構成上その読み出しを最も動かすため、前提条件が解決した。

**この訂正を論文に明記する。** 過去の判定不能は測定系の限界ではなく、対照の設計不備であった。

## BW3. E5a は不成立である

追記73 BV6 は次を登録していた。

> **E5a**: 人間軸の族 (a) および (b) の保留効率が、床 (d) の95パーセンタイルを**超えない**
> 目標が過半を占める。

**感情カテゴリ方向が 12/13 で床を超えたため、E5a は不成立である。**
**約束どおり H1 を介入効率について修正する。** すなわち

> **人間の感情カテゴリ軸は、介入効率において特権的である。**
> **一方、人間の評価次元軸は、分散整合床と区別できない。**

**都合の良い方だけを書かない。** H1 を無条件には維持しない。

## BW4. 循環の否定（主張の前提）

感情カテゴリ方向 $w_e$ は活性から人間ラベルを予測するリッジ回帰であり、勾配方向 $g_e$ は
同じ感情語の出力確率を最も増やす方向である。モデルが正確であれば両者は一致しうるため、
族(a) の効率が族(e) の言い換えである可能性を検証した。

| | 値 |
|---|---|
| 偶然水準 $\lvert\cos\rvert$（$d$=2048） | 0.0221 |
| **$w_e$ と対応する $g_e$** | **中央 0.1526**（最小 0.0216・最大 0.1761） |
| $w_e$ と対応しない $g_{e'}$ | 中央 0.0168 |
| 評価次元 → 勾配（21本からの最大） | 中央 0.0819 |
| 主成分 → 勾配（21本からの最大） | 中央 0.1595 |

**$\lvert\cos\rvert = 0.15$ は1から遠く、族(a) は勾配の言い換えではない。** 一方、対応する組が
対応しない組の約9倍であるため、$w_e$ はその感情に固有の向きを持つ。

**比較の非対称を明記する。** 評価次元と主成分の値は21本からの最大であり、感情方向の
1対1対応より有利な数え方である。それでも主成分は 0.1595 にとどまり床超過は 7〜9/13 である。
**勾配との整合だけでは効率の順序を説明できない。**

## BW5. 先行研究との関係

| | 先行研究 | 本結果 |
|---|---|---|
| 評価次元への介入 | 出力の感情が理論どおり動く（Tak, Banayeeanzade, Bolourani, Kian, Jia, Gratch, Findings of ACL 2025） | **出力摂動量を揃え分散整合床を置くと床を超えない** |
| 感情カテゴリ方向 | 検証対象外 | **床を超える** |

**評価理論が想定する評価から感情への因果経路は、本測定のもとでは支持されない。**
一方、**感情カテゴリ自体は出力に直結する座標を持つ。**

**先行研究の否定として書かない。** 対照の強度に依存する効果であったという**境界条件の同定**
として書く。付録Bの決算表に、全空間床では通り分散整合床では通らないという本研究群の
一貫した観測を併記する。

## BW7. 仮説の更新（追記72 の H1 を修正する）

追記72 の H1 を次に置き換える。

> **H1′**: 人間の感情記述枠組みのうち、**評価次元は**モデル内部の特権的な計算単位ではない。
> **感情カテゴリ軸は介入効率において特権的である。**

**この分岐自体が結果である。** 「人間の概念は特権的でない」という一括した主張は成立せず、
**どの人間概念が特権的でどれがそうでないかを分けて述べる必要がある。**

H2・H3 は未検証のまま維持する。ただし**H2 の動機が変わる。** 感情カテゴリ軸が効率的で
あるならば、model-native な計算モードを探す動機は「人間軸が効かないから」ではなく、
**「感情カテゴリ軸より効率的な座標が存在するか」**になる。
