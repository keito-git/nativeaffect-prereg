## K1. 追記10 の書き漏らし

追記10 で「G1 が未実行なので G1〜G4 すべてを同一モデルで走らせられる」と書いた。**この帰結を明示していなかった。**

**計画B の全体を Qwen3-8B でやり直すということは、軸抽出からやり直すということである。**

- 事前登録本体は層を **5, 7, 10, 12** に固定していた。**これは Apertus-v1.1-1.5B（d=2048）に対して選んだものである**
- **Qwen3-8B は 36層・d=4096** である（中村が実測）。**層5・7・10・12 は、36層のモデルでは極端に浅い側に偏る**
- 軸（ICA 成分）も PMF 床の基底も、**モデルごとに抽出し直さなければならない**

**G4 だけを新モデルで行うことはしない。** G4 は G1 で選んだ軸への介入を測るので、**軸が別モデル由来では G4 の測定に意味がない。**

## K2. 層の選び方（実験前に固定する）

**相対深さを保存する。** 新しい層を恣意的に選ばない。

1. **Apertus-v1.1-1.5B の総層数 N を実測する**（設定ファイルから読む。推定しない）
2. 旧4層の相対深さを **5/N, 7/N, 10/N, 12/N** として算出する
3. **Qwen3-8B（36層）で、その4つの相対深さに最も近い層を選ぶ**
4. **選ばれた層番号と相対深さの対応表を、G1 の実行前に JSON へ記録する**

**この規則を先に書いたので、算出された層が都合の良いものでなくても変更しない。**

**相対深さを使う根拠**: 論文1（AffectGeometry）で、線形復号性のピーク深さがモデル間で揺れ、**相対深さで整列するとモデル間分散が減ることを38モデルで確認している**。層番号の絶対値ではなく相対深さが比較可能な座標である、という所見に従う。
