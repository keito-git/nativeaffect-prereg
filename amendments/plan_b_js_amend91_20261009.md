## CJ1. 同一オントロジーの再符号化検定（検定 CE）——最重要

### 指摘

> 4.4 が示したのは、感情方向が**評価形容詞読み出し**へ転移しないことである。
> 評価形容詞は別の概念体系であり、しかも AUC が 0.55〜0.60 しかない。
> **13感情カテゴリそのものを維持したまま出力表現だけを変える**検定こそが適切である。

**指摘は正しい。** 現在の v4 は「cross-ontology な転移がない」ことしか示していないのに、
タイトルと要旨が「転移の不在」と広く読める書き方になっている。

### 先行性の帰属

**この検定の方法は我々の考案ではない。**
Gao Zhiwei、Peng Shaowen、Wakamiya Shoko、Aramaki Eiji,
"What Does Activation Steering Control? Attribution Across Answer Encodings and
Output-Sensitive Subspaces", arXiv:2608.22985, 2026 が
**Cross-Encoding Steering Evaluation** として提案している。
同論文は、介入を固定したまま回答識別子を付け替えると、steering が意味理解ではなく
**抽出インデックスの追従**を反映している場合があることを示している。

**本追記の貢献は、この検定を感情カテゴリに適用し、分散整合床・探索幅整合・分割整合と
組み合わせることに限られる。** 原稿では「Gao らは**出力符号化**を統制し、
本研究は**活性分散・探索幅・分割の由来**を統制する」と差別化し、
**検定 CE 自体は彼らの方法として引用する。**

### 検定 CE の構成（本追記で固定する。結果を見る前に定義する）

13感情カテゴリを**不透明な1文字コード**へ写し、コード表をプロンプト内に提示する。
枠は次で固定する。

```
Code: anger=Q, boredom=K, disgust=V, fear=Z, guilt=J, joy=X, no-emotion=N,
pride=B, relief=F, sadness=M, shame=G, surprise=W, trust=L

Event: {text}

Answer with the code only. The code is
```

**コード表2（同一の13文字を全カテゴリで入れ替えた完全転置）**:

```
anger=M, boredom=W, disgust=L, fear=J, guilt=G, joy=Z, no-emotion=V,
pride=K, relief=X, sadness=Q, shame=B, surprise=F, trust=N
```

**どのカテゴリもコード表1 と同じ文字を保持しない。**

読み出しは13文字のトークン確率。方向・層・$J^\ast=0.05$・床 F5・統計量は
**一切変更しない**。枠が違うため $\alpha$ は枠ごとに再校正する。
トークン ID の重複は異常終了させる。

### 妥当性検査（判定の前に行う。満たさなければ判定しない）

読み出しB の失敗（AUC 0.55〜0.60 で検定が無情報になった）を繰り返さないため、
**閾値を結果を見る前に定める。**

1. **識別性**：介入なしで13文字の確率が退化していないこと
2. **写像の成立**：当該カテゴリの刺激が他カテゴリの刺激より当該コードに高い確率を与える
   割合（AUC）について、**13カテゴリ中7以上で AUC > 0.5、かつ AUC の中央値 ≥ 0.65**
3. **トークン非重複**

**根拠**：読み出しA の AUC 中央は 0.904〜0.965、読み出しB は 0.553〜0.597 で後者は
無情報であった。**0.65 は、検定が判別力を持つための最低線として先に定める。**

**2 を満たさない場合**：「モデルがコード表課題を遂行できないため検定 CE は無情報」と記録し、
**判定を行わない。コード表を差し替えて再試行しない。**

### 判定 CE（結果を見る前に固定する）

感情族が、コード読み出しの上で F5 整合族最良を超えるか。
**合格条件**：13標的の過半を超え、かつ $p_G<0.01$。これを**モデルの過半**で、
**かつコード表1・2 の両方**で満たすこと。

| 判定 CE | 書けること |
|---|---|
| 合格 | **感情方向の制御は語彙的実現を越える。** 同一オントロジーの別符号化へ転移する。**「人間定義の感情分割は、その語彙的実現を越えた意味的制御を誘導する」** |
| 不合格（妥当性は合格） | **見かけの感情 steering は出力符号化に束縛されている。** 分散整合・ラベル整合を満たす強い効果であっても、符号化を変えると消える。**mechanistic interpretability 全体に効く否定的発見として報告する** |
| 妥当性検査が不合格 | 検定 CE は無情報。どちらも主張しない |

**どちらに転んでもそのまま報告する。**

## CJ2. 4.7 の主張を弱める（即時の修正）

### 指摘

> 無作為分割は真の感情分割と比べて**復号可能性そのものが違う**。
> したがって「人間の感情分割だから」ではなく「意味のある予測可能な分割だから」でも説明できる。

**指摘は正しい。** 4.7 の「人間の感情分割という特定の分割が効いている」は強すぎる。

**修正**：本文・要旨・結論の当該箇所を次に置き換える。

> **人間が定義した感情分割は、クラスサイズを揃えた恣意的な分割を上回る。**

**「あらゆる代替分割より感情が特別」とは書かない。**

## CJ3. 構造整合分割対照（対照 SP）

CJ2 の交絡を潰すため、**復号可能性を揃えた分割**を追加する。

**構成**：刺激の語彙的特徴（文字 n-gram の TF-IDF）で13クラスタに分け、
**感情分割と同一のクラスサイズに合わせる**。さらに
**クラスタ内で感情ラベルを置換する条件付き置換**も併せて作る（表層的な語彙相関を保存する）。
いずれも**保持集合でのプローブ AUC が感情分割のそれと ±0.05 以内に収まる引きのみ採用**する。

**判定 SP**：感情族が対照 SP の族最良を超える標的が過半、かつ $p_G<0.05$（引き数30本のため）。
**モデルの過半**で満たすこと。

**不合格の場合**：「効いているのは感情分割であることではなく、予測可能な分割であること」
と記録し、4.7 の主張をさらに弱める。

## CJ4. 帰無の本数を増やす

### 指摘

> F5 は各方向10本しかなく、4000回ブートストラップしても独立方向は10本である。
> $p_G=0.0005$ という数字ほど裾を直接観測していない。LP も30本で $p_{\min}=0.032$ である。

**指摘は正しい。** 以下に増やす。

| 対象 | 現在 | 変更後 | 根拠 |
|---|---|---|---|
| F5（感情族） | 10本/方向 | **50本/方向** | 符号パターンは $2^d$ あり独立に引ける |
| F5（評価族） | 10本/方向 | 10本（変更なし） | 計算量の配分。**変更しないことを明記する** |
| 対照 LP | 30分割 | **150分割** | $p_{\min} = 1/151 = 0.0066$ |

**ブートストラップではなく、増やした独立標本から直接帰無族を構成する。**
**本数の変更は帰無の分解能を上げるだけであり、統計量と判定基準は変更しない。**
**増やした結果が10本・30本のときと異なる場合、両方を報告する。**

## CJ5. 保持共分散での整合検証と零空間エネルギー

### 指摘

> $D_{\mathrm{fit}}+D_{\mathrm{inner}}$ の標本数より隠れ次元が大きいモデルでは
> 経験共分散に零空間ができる。零空間成分を同ノルムの無作為方向で置換しているが、
> **未知の test 文脈でも分散0とは限らない。**

**指摘は正しい。** 以下を報告する（判定には用いない。診断である）。

1. $\dfrac{\tilde v^\top \Sigma_{\mathrm{test}} \tilde v}{v^\top \Sigma_{\mathrm{test}} v}$
   （$\Sigma_{\mathrm{test}}$ は採点文脈の活性から推定）
2. $\dfrac{\|v_{\mathrm{null}}\|^2}{\|v\|^2}$（方向のうち学習零空間に入る割合）

**本文の記述を「経験 fit 共分散に関して厳密に整合」に改める。**
無条件の「厳密に整合」とは書かない。

## CJ6. 採点文脈の頑健性
