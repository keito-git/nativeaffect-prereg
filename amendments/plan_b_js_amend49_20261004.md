# 第1部：評価次元 steering の分散一致監査

## AX1. 監査対象（公正に記述する）

Tak, Banayeeanzade, Bolourani, Kian, Jia, Gratch (2025) "Mechanistic Interpretability of
Emotion Inference in Large Language Models", ACL 2025, arXiv:2502.05489。

**当該研究が報告していること**（本文 HTML 版により確認）:

- データ: crowd-enVENT（Troiano, Oberländer, Klinger 2023）6,800 件の感情記述、
  13 感情カテゴリ、23 個の自己評定された評価変数
- 手続き: 層ごと・評価次元ごとに線形回帰で $\hat r_a = v_a^\top x + b_a$ を学習し、
  $v_a$ を当該評価次元の表現とする
- 単一効果の分離: $z_a = (I - P_{-a}) v_a$（他の評価次元への射影を除去）
- 介入: 中間層の隠れ状態に $x \leftarrow x + \beta\, z_a/\lVert z_a \rVert_2$
- 効果: 出力の感情ラベル分布の変化
- モデル: Llama 3.2 1B/8B、Gemma 2 2B/9B、OLMo 2 7B/13B、Phi 3.5 mini/Phi 3 medium、
  Ministral 8B、Mistral 12B の10件

**当該研究が置いている対照**: 層の特異性（早期・終端層では効かない）、別タスク（最初の語の
予測）での同手続き、プロンプト頑健性、および付録B の knockout（零/無作為活性への置換）。

**置かれていない対照**: **steering 自体に対する、分散を揃えた面内無作為方向の床。**
介入は単位ノルム方向に $\beta$ を掛ける形であり、**出力摂動量を方向間で揃えていない。**

**この記述は当該論文の HTML 版に基づく。** 本文 PDF と付録を入手して再確認するまで、
論文に「対照が無い」と断定して書かない。**「我々が確認した範囲では見当たらない」と書く。**

## AX2. 問い

> 評価次元方向への介入が感情出力を動かすという報告は、**分散を揃えた面内無作為方向の床**
> のもとで残るか。

論文2 で、軸が全空間からの無作為方向を上回る現象が、**上位主成分部分空間の内部から引いた
分散一致方向**を床にすると12セル中11セルで消えることを示した。評価次元方向は活性に対する
回帰で得られるため、**高分散方向に寄る構造的な理由がある。** したがって同じ交絡を受ける
可能性がある。

## AX3. 対照の階層（論文2 と同一・変更しない）

| 床 | 引き方 |
|---|---|
| F1 全空間 | $\mathbb{R}^d$ の Haar 乱方向 |
| F2 軸直交 | 評価次元方向すべてに直交な部分空間から |
| F3 面内 | 上位 $k$ 主成分部分空間の内部から（$k$ は $z_a$ の 90% を含む最小値） |
| **F4 VMIC** | F3 に加え、**$z_a$ と分散を揃える**（主成分座標での分散プロファイルを一致させる） |

**主たる床は F4 である。** F1 のみでの比較は報告しない。

## AX4. 出力摂動量を揃える

各方向 $v$ について、次トークン分布の JS 乖離（上位100語の和集合上）が目標値 $J^\*$ に
なるよう $\beta$ を個別に二分探索で較正する。$J^\* \in \{0.02, 0.05, 0.10\}$ の3点で測る。

**揃えない比較は報告しない。** 揃えなければ「強く殴った方が動く」だけの結果になる。

## AX5. 効果の測り方（判定者を使わない）

当該研究は出力の感情ラベル分布の変化を見ている。本研究は**判定者を使わない**方針のため、
次の2つを併用する。

- **E1（ラベル確率）**: 13 感情語それぞれの次トークン確率を取り、介入前後の分布変化を
  Jensen–Shannon 乖離で測る。語彙は crowd-enVENT の13カテゴリに固定する
- **E2（符号つき読み出し）**: 追記37 の $S(v) = \tfrac12[R(h+\alpha v) - R(h-\alpha v)]$。
  符号盲を避けるため反対称成分で測る

**両者で結論が一致しない場合、どちらの結論も主張しない。**

## AX6. 判定

**判定 V1（主判定）**: 評価次元方向 $z_a$ の効果が F4（VMIC）の 95 パーセンタイルを超える。
23 評価次元 × モデル × 層 × $J^\*$ の各セルで判定し、**セル単位の通過率**を報告する。

**判定 V2（床の階層）**: F1 → F2 → F3 → F4 と床を厳しくするにつれて通過率がどう変化するかを
報告する。**F1 で通り F4 で落ちるなら、報告されている効果は分散の交絡で説明される。**

**判定 V3（正の対照・前提条件）**: Warriner valence 方向が F4 のもとで E1・E2 を動かすこと。
**動かなければ測定の解像度不足であり、V1 の不成立を主張しない。**
（論文2 で正の対照が面内床に負けた経緯があるため必須とする。）

**帰無の健全性ゲート**（追記45 AT2.5）を全判定に適用する。

## AX7. どちらに転んでも書ける（事前に書いておく）

- **V1 が落ちた場合**: 「評価次元 steering の報告された効果は、分散を揃えた面内床のもとでは
  無作為方向と区別できない」。**反証ではなく境界条件の同定として書く。**
  当該研究の貢献（評価次元が線形に復号できること、層への局在）は否定されない
- **V1 が通った場合**: 「評価次元 steering は最も厳しい床のもとで残る」。
  これは当該研究の追認であり、**本研究の新規性は床の導入にある**と明記する
- **V3 が落ちた場合**: 判定不能として報告し、測定法の改良を今後の課題とする

# 第2部：E5 の帰無を骨格内置換に替える

## AX9. なぜ替えるのか

追記48 AW3 で記録したとおり、E5 では刺激行の置換帰無が平均 +0.8483 に達し、
観測の最小一致 +0.8502 が p95 +0.9155 を超えなかった。**E5 は骨格を共有する格子なので
行が互いに近く、骨格を跨いだ置換が相対表象のプロファイルをほとんど変えない。**

これは帰無の設計不良であり、**E5 における一致の不在を意味しない。**

## AX10. 新しい帰無（結果を見る前に定義する）

**帰無N1′（骨格内置換）**: 骨格を固定し、**同一骨格内でカテゴリの割当のみを置換する**
（500回）。骨格間の差は固定したまま、カテゴリ構造だけを壊す。

**判定 M1′**: 主系列の全対について、表層統計で説明される分を除いた残差の一致が
帰無N1′ の 95 パーセンタイルを上回る。

**帰無の健全性ゲート**: N1′ の標準偏差が 0 でなく、観測との差の 1/10 以上であること。
満たさなければ**判定不能として記録**し、E5 についてそれ以上の主張をしない。
